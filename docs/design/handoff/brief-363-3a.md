## Approved values (lane manager's reading of the boards; where the boards differ, these win)
- **Sub-screen title** (stacked page header): role **title**, 32/600 (`.t-title`).
- **Compact bar** (one component, `app/src/ui/compact-bar.tsx`): fixed at the top, `--color-bg` background, 1px `--color-line` bottom border, row height **44px** (`--touch-min`) on list pages; **56px** on a detail page (`size="detail"`, add token `--compact-bar-detail: 56px`). Content: Back on the start side with the parent's label (reuse the labelled Back from 0156 — the `kicker` label; 15/500 accent-text; if no label, the icon-only Back), then the title, centred, role **btn** (17/500), one line, ellipsis; optional `figure` rendered after the title as " · " + `<bdi dir="ltr">figure</bdi>` (the caller passes a ReactNode, e.g. an `<Amount size="list">`); optional `actions` at the end.
- **Motion:** the bar stays mounted once a page can show it and slides with the motion utilities: `.m-bar-in` (translateY(-110%) → 0, 240ms `--ease-enter`) when it shows, `.m-bar-out` (240ms `--ease-exit`) when it hides; reduced motion = end state at once (tokens already 0ms). Hidden state must not take focus or clicks (`inert` or `visibility:hidden` after the out animation ends — use `animationend`, keep `aria-hidden` in sync).
- **Band** (`app/src/ui/top-band.tsx`): a scroll-linked fade of the band's figures — `--band-fade` = 1 at scrollTop ≤ 60px, 0 at ≥ 220px, linear between (rounded to 0.05), set on the band element by a passive scroll listener throttled with requestAnimationFrame; it follows the finger and is NOT turned off under reduced motion (Motion board, rule "the scroll-linked band fade stays"). Band children that are figures read `opacity: var(--band-fade, 1)` via a class `.ui-band-fade` the caller can put on them; TopBand also exposes `compactBar?: ReactNode` which it shows (m-bar-in) once scrollTop ≥ 220px and hides below. No screen uses these yet (FLOW-364 does) — so to pass `check-unused-app-code`, the Band's fade must be exercised by a story AND a test, and the prop must be used by a real caller: make HomeScreen's existing `<TopBand>` pass nothing new, but use `.ui-band-fade` on nothing yet? NO — if a prop or class has no app user, leave it out: implement only the scroll-linked `--band-fade` variable on TopBand (set on every TopBand; harmless) and the CSS class `.ui-band-fade`, and put `className="ui-band-fade"` on the Hero figure block used by HomeScreen (find it: rg "ui-hero" app/src/ui/hero.tsx). Skip `compactBar` on TopBand (FLOW-364 adds it with Home's bar).
- Keep `html[data-compact-bar]`, `--month-sticky-top` and scroll-padding behaviour (27-compact-header.css ~94-104) working: the counter flips when the bar becomes visible/hidden, as today. The 56px detail size must update the offsets it feeds (use the bar's height token).
