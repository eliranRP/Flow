# FLOW-162: Share the reports as a PDF or a CSV for Excel

- PR: #856
- Kind: sheet, new component; a header action
- Changed: `app/src/screens/report-share-sheet.tsx` (new), `app/src/report-share.ts` (new), `app/src/screens/reports-screen.tsx` (the header's share action), `app/src/ui/icons.tsx` (`ShareIcon`), `app/src/ui/css/61-reports.css` (`.ui-rep-share`).
- Rule:
  - The reports screen's header has one share action ("שיתוף הדוח"). It shows only when the report is in and has lines.
  - The sheet is "שיתוף PDF" or "שיתוף Excel" after the file type. It holds a PDF / Excel switch, the reports in the file (רווח והפסד, מאזן, either or both; the one on screen starts on), "לפרט קטעים מכווצים" (each sub-category under its category; P&L only), one line on what the file holds, and one button, "שיתוף PDF" / "שיתוף Excel". With no report picked, the button is off and the line says "בחרו לפחות דוח אחד."
  - The file has the screen's period, date and projects. The phone's share sheet sends it; where there is none, it downloads with a toast naming the file. A closed share sheet leaves the sheet open. A failure is a toast, "הקובץ לא נוצר. נסו שוב.", and the sheet stays.
  - The PDF follows the board's spec note: A4, Rubik embedded, right to left, the header and footer on every page, repeated table heads, rows that never split, and a page per report, including the by-project page.
- Source: the approved share-sheet board (ReportSharePdf) and the PDF board (ReportPdf), 2026-10-28. On 2026-10-29 the owner chose "PDF + Excel", with the file made on the server and the same file for the assistant (`export_report`).
- Departures from the approved board: the board's live page preview is not drawn, because the file is made on the server when shared. The sheet adds the PDF / Excel switch the owner asked for.
