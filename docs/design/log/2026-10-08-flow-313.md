# FLOW-313: Month totals pause between figures, and a focused row stays put

- PR: #194
- Kind: component
- Changed: `MonthList`. A screen reader heard the month totals run together ("הוצאות −₪2,200הכנסות +$1,500"); each figure now ends with a hidden ", " pause, and nothing changes on screen. A one-month list is now a headless month section keyed by its month, so when a second month loads (or the list goes back to one month) the rows stay mounted and a focused row keeps focus. The unused `className` prop is gone.
- Rule: Figures read in a row get a spoken pause between them (hidden text, not a visible separator). A list that changes its grouping keeps its rows mounted where it can, so focus is not lost.
- Source: FLOW-313 (#98 review).
