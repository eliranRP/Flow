# FLOW-310: focus returns to the opener, with a ring after Escape

- PR: #298
- Kind: component
- Changed: `ui/sheet.tsx` marks the returned control with `data-focus-ring` when the sheet closed by Escape, and drops it on blur (`showRingUntilBlur`). `ui/route-sheet.tsx` does the same for route sheets (`/add`, `/review/change`). Only a close that goes ahead counts: an Escape the sheet handles itself (`onEscape`) or that `onBeforeClose` refuses leaves no mark for a later ✕. The CSS draws the existing focus outline (buttons, icon buttons, chips, segments, hits, text links, ring rows, labelled Back, band controls) and the row tint (`.ui-row`, `.ui-radio-row`) for `[data-focus-ring]:focus` too, because a programmatic focus after a key press does not always match `:focus-visible`. ✕ and a tap return focus with no ring. Settings → Categories passes `returnFocusRef` to the create, merge pick, merge confirm, hide confirm and move sheets. No new look: the ring and tint are the ones keyboard focus already shows. Story: Components/Sheet Return Focus After Escape.
- Rule: A sheet closed with Escape returns focus to its opener with the focus ring showing; a sheet closed by touch returns focus with no ring.
- Source: FLOW-310 (backlog nit, sheets and focus).
