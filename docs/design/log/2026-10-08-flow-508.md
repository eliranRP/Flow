# FLOW-508: Connect sheets check empty fields in place

- PR: (this PR)
- Kind: component
- Changed: `mercury-connect-sheet.tsx`, `sumit-connect-sheet.tsx`. An empty (or blank) key or SUMIT company number no longer goes to the server and comes back as a toast. The field shows "חסר מפתח." or "חסר מספר חברה." on its reserved message line, and focus moves to the first empty field. Typing clears the message, and a closed sheet opens again without it. The key and company fields are read-only while connecting. Stories: Components/ConnectSheets.
- Rule: A connect or setup form checks required fields on submit, before any request. The message sits on the field's reserved message line (`reserveMessage`, so the button does not move), in the "חסר X." form, and focus goes to the first empty field. Fields are read-only while the submit is busy.
- Source: FLOW-508 (settings and connect sheet follow-ups); copy follows the loan setup form ("חסר מלווה.").
