- **Pages:** review queue and card, line split, review change, transaction, action bar, search, swipe row, related charges, transfer matches, journal, journal composer, transaction thread, rule offer.

The approved prototype applied to these screens (the owner, 2026-11-13). Spacing is on the 4-pt grid: the 2, 6, 10, 14 and 18px steps and the calc() arithmetic became space tokens (about 100 values). Cards and surfaces carry `--shadow-sm`; the tinted rule offer stays flat. Concentric corners where a control sits in a tight padded track (line-split segment, composer debit/credit switch, search filter segment); the thread bubble keeps the card's inner corner, since it is a message surface, not a control in a track. The 12px sizes use `--type-label-size`. Line-split's segment track grew from 40 to 44px (`--touch-min`) to hold its 36px buttons inside the new 4px padding. The transaction back row's pull-up moves from -10 to -12px. At 320 the review-all meta line ellipsizes a few px earlier (row gap 14 to 16); the project name stays whole.

Proof: 31 Storybook stories at 320 and 393, light and dark, before and after, looked at; the story tests for these screens pass.
