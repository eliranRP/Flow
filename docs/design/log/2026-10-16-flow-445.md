## Decisions made while building

- **The project type comes from the month's row.** The project detail read has no type field; the
  row from `projects_cash_month` does. A `state_label` ("פעיל") was used as the type before and would
  have overwritten the owner's type on save.
- **`upsert_project` keeps the stored type** when the edit sheet's type field is empty and the stored
  type is not known. An empty field clears it only when a stored type is known.
- **The compact bar's figure can come first.** `CompactBar` takes `figureFirst`, used on the project
  page only; the list keeps the title first.

## Known differences (intentional or deferred)

- Finish navigates to the Projects list, not the project page (brief).
- The investment row shows only when an investment figure is set (the brief says every non-overhead
  project).
- The delete row title uses the menu row style, not the signal colour.
- `upsert_project` does not clear a budget when the budget field is left empty.
