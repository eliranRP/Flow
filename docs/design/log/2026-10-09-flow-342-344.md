# FLOW-342 and FLOW-344: one magnifier on Projects; the loan preview hides until the form is valid

- PR: #314
- Kind: screen
- Changed: The Projects tab drops its header magnifier, so the project filter is the page's one search. When the typed text matches no project, the "לא מצאנו" empty state gives way to one row: a magnifier, "חיפוש בתנועות: {text}" and a chevron, which opens Search with the text typed. The field's ✕ clears the filter. Transaction search stays one tap away on Home's band. In the new-loan form, the payment preview (monthly payment, total interest, final payment) shows only while every field is valid; with a field empty or wrong it is gone, not dimmed, so it never reads as this loan's payment.
- Rule: One search entry per screen; a filter that misses offers the wider search as a row with the typed text, not an empty state. A computed preview shows only for valid input; it never keeps a stale result, dimmed or not.
- Source: FLOW-342 option A and FLOW-344 option B, both the owner's picks on 2026-10-09 (cycle 6 and cycle 7 reviews).

## Split lines on the project page

- PR: #314
- Kind: screen
- Changed: A row for a transaction split across projects shows the project's part as its amount; the hint starts with "מתוך {whole}" so the full line is still visible. Rows that are not split, or kept out of the project, are unchanged.
- Rule: A list scoped to one project shows each line's amount for that project; a split line names its whole amount in the hint, never as the main figure.
- Source: owner's request on 2026-10-09 (the Wickliff example: show the ₪250 part, not the whole bill).
