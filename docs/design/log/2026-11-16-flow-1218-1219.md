# FLOW-1218, FLOW-1219: the profit head waits for its month count; the project ⋯ menu says when it is checking

- PR: #TBD
- Kind: fix
- Changed:
  - `app/src/screens/project-profit-screen.tsx`: the לפי חודש head passes no count while the months load or fail (`profitSummary` takes a null count and shows the profit alone), so it no longer reads "• 0". The by-year heads already wait for the months.
  - `app/src/screens/project-menu.tsx`: while the menu's figures load, its list is `aria-busy` and a visually hidden `role="status"` line says "בודקים אם אפשר למחוק…"; it is empty when the read lands or fails. The visible layout is unchanged.
  - `app/src/ui/list-row.tsx`: `List` takes a `busy` prop that sets `aria-busy`.
  - Tests and stories: `project-profit-loading.test.tsx`, `project-menu-figures.test.tsx`, and the stories "Project, ⋯ menu while checking" and "Project, ⋯ menu, check failed" in `project-detail-screen.stories.tsx`.
- Rule:
  - A group head's count waits for the read that gives it. While the rows load or fail, the head shows only what is already known (the profit), never a count of zero.
  - A menu or sheet whose figures are still being read marks its list `aria-busy` and says so in a live status line that is cleared when the read lands or fails. The visible layout does not change.
- Source: UX rules review 2026-11-16 (the owner asked for the fixes).
