## Differences from the board

1. **Currency.** The board shows `$`. The form shows the company's currency: `₪` for shekels, `$` for dollars. The preview company is USD, so it shows `$`.
2. **Bank row.** The board moves the bank connection to Settings › חיבורים. The row stays in the + sheet for now: its test (`add-sheet.test.tsx`) belongs to PR #633, so it is not edited here. The move follows #633.
3. **Sample data.** The preview uses invented names, not the board's names.
4. **Camera, reading, suggestion.** The board's AddCamera, AddReading and AddReceipt reading step, and the supplier suggestion line, are not built here. They are FLOW-917. The receipt form opens with the file attached and the fields empty.
5. **Overhead.** "בלי פרויקט" is a chip on the form, not a project; it saves the line with no project.
