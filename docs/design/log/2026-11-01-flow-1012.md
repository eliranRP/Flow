# FLOW-1012: The forecast screens: one save on an item's page, dates first, צפי once

- PR: #930
- Kind: screen
- Changed: `app/src/screens/forecast-item-page.tsx` (the כל כמה זמן row and the hint), `forecast-parts.tsx` (`itemWhat`, the row's second line), `forecast-category-view.tsx` (the view chips), `forecast-screen.tsx` (the add button with one project), `company-next-month-screen.tsx` (section heads, row hints, the kept row), `app/src/ui/css/51-next-month.css` (`.ui-cn-head > .ui-fc-tag` removed).
- Rule:
  - A page with one save button drafts every choice on it, a sheet's pick included, and writes them all with that button; nothing on the page says a thing stays unchanged once a pick will change it.
  - A forecast row's second line puts the date first ("עד 10/11 · חשבונית #1047"), so a narrow screen cuts the document's name, never the date. A line the owner added is named with a noun, "שורה בצפי".
  - A screen titled "צפי …" does not repeat צפי in its section heads or row hints.
  - A row with no link inside a list of rows that open fades (`setAside`), so it does not look tappable.
  - The forecast's view chips are one word each (פריטים, פרויקטים, קטגוריות) in a radiogroup named "תצוגה לפי".
- Source: UX rules review 2026-11-01 (the owner asked for the fixes). FLOW-1012, FLOW-1013.
