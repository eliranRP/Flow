- Departures from the board:
  - The date row's grey line shows no transaction estimate ("כ־2,900 תנועות"): Flow has no count before the first sync. It says "בפעם הראשונה זה לוקח כמה דקות" for מההתחלה and the start day for the others.
  - The account type line is the kind only (עו״ש, חיסכון, כרטיס אשראי, Mercury Treasury · השקעה); the board's "· רוב התנועות של העסק" for the busiest checking needs counts Flow does not have before the sync.
  - מתאריך picks its day with the app's date sheet (a field that opens the calendar), not a typed dd/mm/yyyy field, as the other import dates do; the day starts on 1 January.
  - On the synced accounts list the date sheet adds a first choice מהיום (rows only from today), the default for an account checked there; the note says a new account starts today, and the board's sheet has no such row.
  - "כן, לסנכרן" on a new account reads it from the connection's own start (a new account has little history), where the board just adds it.
  - The connection list's line uses the app's sync phrase ("עודכן ב-06:05", "עודכן אתמול ב-…") instead of "עודכן לפני 5 דקות".
  - "+ חיבור Mercury נוסף" on the one connection's page is a link-style button like the others there; the step's title is an h2 at the section size instead of the grey numbered head.
  - The organisation fact shows only once Mercury has sent the name (the next sync for a connection from before).
