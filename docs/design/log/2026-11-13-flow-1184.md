# FLOW-1184 · A forecast row leaves for one month, or from it on

- **Kind:** behaviour
- **Rule:** none (decision 0268)
- **PR:** #1158
- **Pages:** תזרים צפוי › an added line's page; a project's צפי › a row's edit page.

The owner, 2026-11-13: a line added to the forecast stayed in the month after it was removed, could not be removed from its own page, and could only be removed for every month to come.

- The added line's page in תזרים צפוי gets הסרה מהצפי: a red link under שמירת השינוי בצפי (the project edit page's danger-link, same place relative to the save).
- הסרה מהצפי, on both pages, opens a ChoiceSheet in the pace sheet's frame (`ui-pace-sheet`) with two radios: רק ב<month> ("ב<next month> הוא צפוי כרגיל") and מ<month> והלאה ("לא יופיע בצפי של החודשים הבאים"). No radio is checked: the pick is the action. A line added for its month only has no month after it, so it goes at once.
- Story: `Project, next month forecast, remove a row`. The item page's link shows in `Forecast · change an added line, pace picked`.
