# Design log

One file per UI PR that changes how Flow looks or behaves: `YYYY-MM-DD-flow-<id>.md`. The format and the rules for when a change also needs a DESIGN-RULES edit or a decision record are in [DESIGN-TEAM.md](../DESIGN-TEAM.md#recording-a-design-change).

The design lead reads new entries after each deploy batch and keeps [DESIGN-RULES.md](../DESIGN-RULES.md) in step with them.

Earlier design history is in the [decision records](../../decisions/README.md) (look for UI decisions such as 0120) and the [changelog](../../changelog.md).
