# Design log

One file per UI PR that changes how Flow looks or behaves: `YYYY-MM-DD-flow-<id>.md`, named by the first id in the PR title (or a short slug when there is none). The format, the `Rule:` line the design lead copies into DESIGN-RULES, and when a change also needs a decision record are in [DESIGN-TEAM.md](../DESIGN-TEAM.md#recording-a-design-change).

The design lead reads new entries after each deploy batch and copies their `Rule:` lines into [DESIGN-RULES.md](../DESIGN-RULES.md) in the cycle's backlog PR.

Earlier design history is in the [decision records](../../decisions/README.md) (look for UI decisions such as 0120) and the [changelog](../../changelog.md).
