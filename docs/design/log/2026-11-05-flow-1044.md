- Rule:
  - A project's kind (renovation, rental, client, overhead) is resolved in `resolveProjectKind`: the overhead project is overhead; a type word that names a kind wins (the new-project sheet stores its pick as the type word: שיפוץ, השכרה, לקוח, תקורה); else a budget or ARV is a renovation, a rent or a property value a rental, anything else a client. No column.
  - A list in groups by kind uses `GroupHead summary` with "count · total" in the list's currency, kinds in the order שיפוץ, השכרה, לקוח, תקורה; a kind with no row is left out.
  - An Overview screen with a band and no month drawer (Projects, project profit) uses the band bar (`CompactBar` with `tone="band"` and a `centre` of `ui-compact-bar-centre-title` and `-net`), docked through `useDockedFilter({ bar: 64 })`, its mark at the band's end. The project page keeps its detail bar (`figureFirst`, `bar: DETAIL_BAR`) with the dock.
  - A screen's attention rows carry `dismissKey` = row id plus what the row counts; the review row never carries one.
  - A confirm that moves an item to another list (finish) is a second view inside the same sheet, titled with the question, with the main button and חזרה; the optimistic write and its ביטול toast follow as before.
  - A row with its own action beside the link (שיוך) puts the button next to the row, never inside it (`ui-unassigned-row`).
