# FLOW-702: Jev mode and threshold in Connections → תיוג חכם

- PR: #231
- Kind: screen
- Changed: the Jev card's אפשרויות panel (app/src/screens/jev-settings.tsx) now holds a "מצב" segmented control (הצעות בלבד / מילוי אוטומטי) with its hint, and, in auto mode only, a "סף ביטחון" segmented control (80% / 85% / 90% / 95%, 90% by default). A stored threshold that is not one of the four selects none and says "הסף כרגע N%". Both controls are disabled while a save runs and for a viewer. The status line reads "פעיל · הצעות בלבד" or "פעיל · מילוי אוטומטי". New `.ui-jev-options-panel` block in css/10-settings-onboarding.css; stories OnAuto (+ dark, 320) and OnAutoCustomThreshold
- Rule: A setting with two to four short fixed values that sits inside a card uses SegmentedControl, applies on tap and saves at once (no confirm). A dependent setting appears under the control that enables it and is hidden, not disabled, while that control's value makes it meaningless. The plan's "chips" for the threshold are a SegmentedControl, for radio semantics and to match the mode control.
