# FLOW-334 leftovers (UI lane 2): שויכו היום by project, tint error actions, review-cycle fixtures

- PR: #310
- Kind: component
- Changed: `ui/month-list.tsx` (`GroupList`), `ui/month-groups.ts` (`groupByKey`), `css/11-month-lists.css` (`.ui-group-title`, `.ui-group-head`, `.ui-group-count`), `screens/filed-today-screen.tsx`: שויכו היום puts its rows under one sticky head per project, in the order each project first appears. The head is the month head's shape: the project name in `heading` (wraps to 2 lines, then cuts), then the line count in muted `meta` ("3 תנועות", "תנועה אחת") 12px before the income and expense totals, which add up the rows as shown (cents included, as the rows show them). A line with no project goes under "בלי פרויקט". Each row's hint is now only its category. Prev and next on the card step through the rows in the order drawn. `ui/error-state.tsx`: the retry drops the filled `.ui-btn-retry`, so the Review, Home and every other error state use the same 44px tint button as Home's empty state (was a filled primary). `ui/tab-bar.tsx`: an optional `section` names the lit tab where the path can't (dev fixtures only). Dev only: the `/e2e/*` fixtures of tab screens draw the tab bar, `/flow/*?preview=1` shows sample figures, `/reviewer/transaction/1` opens the first sample row. Stories: Screens/Routes Filed today by project (light, dark, 320, dark 320); Components/ErrorState Server Dark, Server 320, Offline Dark 320; Components/EmptyState Default Dark, Default 320.
- Rule: A list grouped by something other than the month (שויכו היום by project) uses the month head's shape: the group name, then its line count in muted `meta`, then its totals; the rows then drop what the head already says. Every empty and error state action is the 44px tint button, never a filled primary; a retry included.
