# Where a screen's time goes, 2026-11-23

The perf steward's split of an in-app visit to each main screen, for decision [0271](../../decisions/0271-half-second-by-kept-data-and-one-wave.md). Production `36cb136`, measured about 12:36 UTC, signed in as the Flow QA owner.

## Method

The FLOW-804 phone: 412×915 mobile viewport, CPU slowed 4× (`Emulation.setCPUThrottlingRate`), 85 ms latency, 9 Mbps down and 1.5 Mbps up. Each run uses a fresh browser context:
1. Open Home and wait until it settles.
2. Make an in-app visit to the screen (`history.pushState` and `popstate`, as a tap does).
3. Watch for 6 s.

The table gives the median of 3 runs per screen.

| Measure | What it counts |
| --- | --- |
| Settled | No skeleton or busy marker (`.ui-skeleton-bar`, `.ui-skel-row`, `.ui-skel-leaving`, `[aria-busy=true]`, `.ui-chart-skeleton`), and the page's last DOM change. Both are measured from the visit. |
| Main thread | The CDP `Performance.getMetrics` `TaskDuration` delta over the whole 6 s window. It is an upper bound, because it includes work after the page settles. |
| Network busy | The union of the Supabase REST request intervals that start before the settle point. |
| Waves | Groups of request starts more than 250 ms apart. |
| Requests | Every Supabase REST request, including duplicates. |

## Why these times are later than the daily report's

The [daily report](2026-11-23.md) (section 3, production `dc189b8`, 01:17 UTC) gives earlier times for some screens:
- Profit month figures at 906 to 1,042 ms;
- Profit year figures at 648 to 742 ms;
- Review's first card at 805 to 1,124 ms.

Those are the first figures drawn. The settled times here are the end of the visit: the last skeleton gone and the page stopped changing. Profit's year view settles at 1,595 to 1,905 ms in the daily report too.

The project page's no-skeleton time agrees: 2,189 to 2,246 ms in the daily report, against 1,865 to 2,330 ms here.

The daily report does not time Recurring's settle point.

Production changed between the two runs, from `dc189b8` to `36cb136` (#1252, #1254, #1255).
