# Hebrew only in this phase

**Date:** 2026-09-26
**Status:** Accepted

## Context

The interface is already Hebrew and right to left. A second language at launch means every label, notification, and empty state exists twice before the first contractor has a project P&L.

## Decision

This phase is Hebrew only. Layout is right to left. Amounts stay ₪, with the number itself left to right.

## Alternatives rejected

Multi-language at launch.

## Consequences

No language picker. Product copy in the app, including notifications and onboarding, is Hebrew. English in this repository is for the spec, not for the UI. A later language is a new decision.
