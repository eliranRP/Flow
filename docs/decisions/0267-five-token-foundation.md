# 0267 · Five tokens: two shadows, a label size, the 4-pt spacing rule

- **Date:** 2026-11-13
- **Status:** accepted (the owner, 2026-11-13: asked for the five-token design system skill to be applied, then "Yes approve" the prototype sheets as shown)
- **Context:** the skill `five-token-design-system` (colour roles, 4-pt spacing, a small type scale, nested radius, two shadows) was run over the app as a read-only audit. DESIGN-RULES §2.6 allowed no shadow scale and no card shadow; §2.4 kept the v3 boards' in-between spacing values (2, 6, 10, 14, 18px, decision 0257); there was no token for the 12px label, which many screens spell as a raw size. The owner approved a prototype showing a faint card shadow, the 12px label token, spacing on the 4-pt grid and concentric corners where a control sits in a tight track.
- **Decision:** (1) two shadows and no others: `--shadow-sm` for cards and surfaces, `--shadow-lg` (today's toast shadow) for floating layers; `--shadow-pill` and `--shadow-toast` become aliases of `--shadow-lg`; both have light and dark values. (2) `--type-label-size` is 12px (with line 1.4 and weight 400); the role scale otherwise stays. (3) Every spacing value is on the 4-pt grid (4, 8, 12, 16, 20, 24, 32, 40) through a space token, with no `calc()` arithmetic; the 2, 6, 10, 14 and 18px steps are retired; hairlines, borders and focus rings are not spacing. (4) Nested radius: outer = inner + padding where a rounded control sits in a tight padded rounded track. (5) The skill is kept in the repo at `.claude/skills/five-token-design-system/SKILL.md`; DESIGN-RULES and the owner's decisions win over it.
- **Consequences:** this record amends 0257 for spacing only (its type, radii, heights and order stand; 0258 stands). It replaces the "no shadow scale" line of DESIGN-RULES §2.6. This change adds the tokens, the rules and the skill; each screen area adopts them in its own PR, so cards gain `--shadow-sm` area by area. The two dark token blocks are now checked to set the same properties (the forced-dark block lacked `--color-movie-from`; fixed).
- **Alternatives rejected:** keeping the in-between steps where a board has them (the owner chose one grid); a third, medium shadow for menus and sheets (two levels is the rule); keeping cards flat (the owner approved the faint shadow).
