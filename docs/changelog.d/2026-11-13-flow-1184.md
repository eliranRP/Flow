**FLOW-1184 (forecast removals).** A line you added to a project's forecast can now be removed from its page in תזרים צפוי. Before, it could only be removed from the project's צפי page, which opens next month, so it stayed in this month's forecast. הסרה מהצפי now asks: רק ב<month> (that month only; the next month expects it as usual) or מ<month> והלאה. The project's צפי edit page asks the same for every row, and the MCP tool `remove_project_forecast_row` takes `pace` (`once` or `month`).
