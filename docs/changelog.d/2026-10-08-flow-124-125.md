The transaction lists (category drill-down, a project's waiting rows, review, filed today, breakdown lines) now return each row's `source` and `kept_out`, so the app can show the bank icon and the ⊘ mark. `get_transaction` and MCP `get_expense` return `pnl_state`: `in`, `out`, or `mixed` for a line split by category with a part kept out.
