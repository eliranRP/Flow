Web push, server part 1 (FLOW-502, option A). Each device's push subscription and each user's three switches (תנועה חדשה, תזכורת ערב, סיכום שבועי; all off until turned on) are saved through new RPCs: `push_subscribe`, `push_unsubscribe`, `get_notification_prefs`, `set_notification_prefs` and `answer_push_prompt`. A new `push-send` function sends the evening reminder at 20:00 Israel time to owners who turned it on and have lines waiting in לאישור, once a day, with the count from SQL. It encrypts with Web Push (VAPID) and posts only to the browsers' push services. The VAPID keys are function secrets the owner sets once ([push.md](../runbooks/push.md)). The app screens come in a UI PR. Also: a Mercury line first seen as failed or cancelled no longer counts as a new line.
