Month dividers in transaction lists (FLOW-302, the designer's option A). A project's recent list, the category drill-down, and both לאישור lists show a sticky header for each month, with that month's income (+) and expenses (−) per currency, ILS first, never converted. Each total adds up the rows' shown whole amounts, so the header matches the rows. A list from a single month, or one whose held order splits a month, stays as before; the last month of a list that may load more rows shows its name only. A focused row scrolls in below the pinned bar. Shared component `MonthList` (`app/src/ui/month-list.tsx`). No migration and no MCP change: the grouping is display only. Mockups: option A of the [design canvas](https://claude.ai/artifact/AHkHqk9WgUeCXb9wHYwdVB). Follow-ups are FLOW-313.
