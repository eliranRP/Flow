FLOW-1343: Home stops loading setup for a card that draws nothing. The setup slot and its completed-toast rule are gone, so a cold Home no longer loads the setup code or reads the setup steps for an owner whose run is open but already resumed, and one cold start makes at most one read of the saved setup row (the resume code reuses the check's answer). An owner whose run finished, skipped everything or already resumed, with a saved copy on the phone, makes no read at all. Mid-setup owners are still sent back to their step once, and an owner with no company still reaches the welcome screen. Saved setup rows that still hold the old card and toast stamps load as before. Behavior change: a run this phone finished, skipped or resumed is not resumed again on Home's cold start even when the server row lacks the stamp; the next time the setup store mounts (Settings, /setup) the server row still replaces the local copy.
