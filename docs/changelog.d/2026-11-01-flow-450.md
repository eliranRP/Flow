A property's returns, the way *Real Estate by the Numbers* analyses a rental (FLOW-450, decision [0244](decisions/0244-property-returns.md)). `get_property_returns` gives a project's cash-flow statement for a period (income, operating expenses, NOI, loan payments, CapEx, cash flow, not counted), the four sources of return (cash flow, principal paid, appreciation, tax savings) and their total on the money in the deal, the equity figures (equity today, forced equity, money in the deal) and the metrics (cash-on-cash, cap rate, DSCR, cash flow per unit). A figure whose input is missing is null with the input named; nothing is guessed. `get_property_return_lines` lists the lines behind any figure. New inputs: the property's units and land value (`set_project_investment`), and the owner's tax bracket (`set_tax_bracket`, undo `tax_bracket`). Every value set on a project is now kept by its date (`project_values`), for appreciation.
