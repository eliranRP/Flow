Each open invoice on Unpaid now carries its SUMIT document link (FLOW-335, server part). When a sync finds an open SUMIT invoice with no stored link, it makes one `accounting/documents/list` read (tax invoices only, from the earliest such invoice's date) and stores each document's download link when it is on `https://pay.sumit.co.il/`; a sync with nothing new to link makes no extra call, since every call counts against the customer's SUMIT quota. Links on any other host are dropped, and a sync that cannot read the list keeps the links it has. `list_unpaid` and `UnpaidRow` gain `document_url` (null until a sync reads it), so the app can open the invoice from its row. The link opens the document without a SUMIT sign-in, so it is shown only to the company's owner and viewers, like the rest of the row. MCP `list_unpaid` returns it too ([TOOLS.md](mcp/TOOLS.md)).
