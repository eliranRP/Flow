Each open invoice on Unpaid now carries its SUMIT document link (FLOW-335, server part). The SUMIT sync also reads `accounting/documents/list` and stores each document's download link when it is on `https://pay.sumit.co.il/`; links on any other host are dropped, and a sync that cannot read the list keeps the links it has. `list_unpaid` and `UnpaidRow` gain `document_url` (null until a sync reads it), so the app can open the invoice from its row. MCP `list_unpaid` returns it too ([TOOLS.md](mcp/TOOLS.md)).
