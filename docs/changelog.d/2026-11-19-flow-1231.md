FLOW-1231: the project page reads the loan balances of its own project only. The `loan_balances` view gains a last column, `project_id` (the loan's project; everything else in it, its grants and its row-level security are unchanged), and the forecast's loans read filters the balances by it, next to the loans read it already runs at the same time. Before, every project page made the server total all of the company's loans and send every balance row back; on Flow QA that read went from 22 rows (3,643 bytes of JSON, 21 ms) to the project's own (2 rows, 330 bytes, about 6 ms). The company-wide forecast read is unchanged. Affects the project page's forecast (decision 0230).
