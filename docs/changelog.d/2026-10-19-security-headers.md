The app sends security headers on every path (decision 0192): X-Frame-Options DENY so no site can frame the owner screens, nosniff, a strict-origin-when-cross-origin referrer, a Permissions-Policy that turns off the camera, microphone, location and other device features the app does not use, HSTS for a year, and a Content-Security-Policy in report-only mode. The build writes the policy into `dist/_headers` with the hash of the inline theme script and the Supabase origin; `scripts/security-headers.test.mjs` checks it. Zod now runs without its eval probe so the policy needs no `'unsafe-eval'`. The CSP is enforced after two weeks with no violations.
