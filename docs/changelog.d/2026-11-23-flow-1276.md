**Perf (FLOW-1276, decision 0271):** a repo script, `pnpm sweep` (`scripts/screen-sweep.mjs`), reports the three times of decision 0271 for Home and every main screen on the FLOW-804 phone: data shown (a repeat visit with the screen's kept data on the device), fresh data shown (every first-view read answered and drawn, taken from the requests) and first visit (an empty store, background reads off). It also prints each visit's main-thread time, network busy, request waves, request count and KB, as medians of 3 runs with every run's values, as a table or JSON. It signs in with a session file the caller already has and never prints it. Nothing in the app changes; the first sweep sets the baseline of all three times.
