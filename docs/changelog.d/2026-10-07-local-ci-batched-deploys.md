Pull requests are checked locally, and `main` deploys in batches. A pre-push hook runs `scripts/local-ci.sh` (lint, the core checks, and the Storybook tests, about 4 minutes) and stops a push that fails. GitHub no longer runs CI on pull requests, so an approved PR merges right away. `main` runs the full suite and deploys after every 5 merges, or when someone runs the `ci` workflow by hand.
