The pre-push local CI now runs the e2e specs for the screens a push changes (FLOW-813 follow-up, [TASKS](backlog/TASKS.md#flow-813)). `app/e2e/spec-sources.json` maps each spec to the screens it opens, and `scripts/e2e-specs.mjs` follows their imports to pick the specs that reach the changed files. A copy change in one screen runs about 9 specs in 3 minutes; server and docs pushes run none. It needs Docker for local Supabase, and without it the run names the specs it left to main.
