The push gate's base-risk check (#400) now re-runs only what main's change can affect when an unchanged patch meets a newer main: a migration or the seed re-runs the database step (every pgTAP file on a database branch) and the e2e specs the branch reaches; flow-mcp re-runs its Deno tests and the smoke; packages/shared re-runs the typecheck, unit tests and builds. Lint, Storybook and the smoke stay skipped. A mark with no fork, or a fork no longer under main, still runs the whole gate.
