FLOW-114 (loan match server items, [0136](decisions/0136-loan-unmatch.md)). A loan payment can be unmatched in one call: `clear_loan_split` (owner only) removes its parts, and the line keeps its project and category and counts whole again. MCP gains `detach_loan_payment`; undo kind `loan_detach` puts the same parts back, or is a conflict when the line was matched again or the parts no longer fit. `get_transaction` (and MCP `get_expense`) returns `loan_split`, so one read is enough. The unmatch button, the locked category picker and writing through `save_loan_split` go through a UI lane.
