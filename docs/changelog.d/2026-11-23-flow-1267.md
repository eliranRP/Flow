FLOW-1267: the main screens' reads are kept on the phone and drawn at once on a repeat visit. The first-view reads of Home, Projects, the project page, Loans, Recurring, Profit (a month, a year, any dates), Review's first page and the forecast are saved in IndexedDB after each successful read and put back into the query cache as soon as the app starts (about 300 ms after the first render at CPU x4 on 4G, before any other screen opens; the first render does not wait for it, because waiting made the screens slower, not faster). A kept read is drawn as stale and its query reads again at once, so the figures never stay old; `useKeptState(queryKey)` says while a kept read is on screen and its refresh is in flight, for the hint that FLOW-1268 draws (no screen changes here). Each row names the user and the shown company it was read for and is never put back for another; rows older than 7 days, of an older kept-data version (`KEPT_VERSION`) or that no longer fit their read's schema are dropped; sign-out, a user switch and a change of the company's basis clear all of them; the store holds about 5 MB and drops the oldest first. It replaces the project page's own localStorage copy (`project-cache.ts`) and the company currency's, which are gone.
