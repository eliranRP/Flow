New `save_loan_split(p_transaction_id, p_loan_id, p_parts, p_preview)`: the app's one write for a loan split, attaching a payment or replacing the split of a line already on the same loan in one transaction under the loan lock, with the same part checks as MCP `attach_loan_payment` (`p_preview` checks without writing). A demand loan's order checks (`payment before the loan start`, `a later payment is already attached`) now run in the database under the loan lock, in `save_loan_split` and in `mcp_attach_loan_payment`, so two attaches cannot take the same interest base. `mcp_loan_payments` returns a demo viewer's payments. A loan rate dated before its loan's start is refused in the database, and so is moving a start after a rate (FLOW-136). A line on an open loan is no longer flagged for review because another write held the loan (FLOW-136).
