FLOW-445, server side of the Projects tab (decision 0176 and the brief's data plan). A project now has a type text (`upsert_project` takes `p_type`, at most 40 characters, stored in `state_label`) and a finish date (`projects.finished_on`, set when the project finishes, cleared when it is made active again). `projects_cash_month` gives one month's cash per project, the overhead project's included, and the unassigned bucket; the projects plus unassigned add up to `cash_months` for the same month. `delete_project` removes a project only when nothing refers to it, and says `in use` otherwise. The MCP gains `update_project` and `delete_project` (both with an idempotency key, the write rate limit and undo), and `create_project` takes `type` and `budget_minor`. See [TOOLS.md](../mcp/TOOLS.md).
