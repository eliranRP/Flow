The `pr` check splits its work further so it finishes sooner (FLOW-835). The typecheck and the unused-code and CSS checks now run in their own job, `pr (types)`, beside `pr (static)`. The `pr` check now needs the types job too. The target is 100 seconds or less for the whole check.
