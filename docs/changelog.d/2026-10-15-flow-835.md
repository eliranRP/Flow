The `pr` check splits its work further so it finishes sooner (FLOW-835). The typecheck and the unused-code and CSS checks now run in their own job, `pr (types)`, beside `pr (static)`. The app's unit and Storybook tests run in six shards instead of three. The static, types and db jobs read main's pnpm store from the cache, and no PR job saves one after its steps any more (that save took 15 to 18 seconds in the Playwright container); `main` still saves it. The Playwright test shards could not read that cache, so they install cold, which takes a few seconds. The `pr` check now needs the types job too. The target is 100 seconds or less for the whole check.
