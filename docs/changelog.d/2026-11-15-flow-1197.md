FLOW-1197: a held sync change the owner set aside with אישור stays set aside, also after the closed date moves back: the next sync applies only held changes, not left ones (the fetched line still wins; a new provider change is held again); reopening a left row (reopen_review or any undo) makes its hold held again, so an open row always has a held hold. To take a left change, undo the leave first (it goes back to held), then move the closed date back. `docs/mcp/TOOLS.md`, the flow-mcp tool text and `docs/tech/state-machines.md` say so.
