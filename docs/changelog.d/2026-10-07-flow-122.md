Loan categories by key in the app and the Mercury hint (FLOW-122). The transaction's loan match, the parts it files, and the fixed line on the categories screen now find the three loan categories by `categories.loan_part`, not by their Hebrew names, so a renamed loan category keeps working. The Mercury connector's loan hint is now `loan_part:principal`; migration `20261007222000_loan_hint_by_key.sql` lets `upsert_connector_lines` resolve a `loan_part:<part>` hint by key (any other hint still matches by name). No visible change and no MCP change.
Deploy note: CI deploys `mercury-sync` before it pushes the migration, so a Mercury sync in that window (or after a failed push) sends `loan_part:principal` to the old `upsert_connector_lines`, which finds no category by that name; those loan lines get only the usual guess until a later sync re-sends them.
