The every-story Storybook smoke loads the manager once per shard and opens each next story in place through the manager's own router, the way a click in the sidebar does, then waits for the preview to finish rendering it. A story that shows any problem in place is opened again on a fresh page with the old one-page-per-story check, and only that result counts. Same checks per story (console errors, page errors, blank manager, the outside-request guard); one shard alone went from 3.9 to 2.2 minutes, and the full run with 4 workers took 4.7 minutes in a cloud container.
