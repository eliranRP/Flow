A loan can be paid off or closed ([0122](decisions/0122-loan-status.md), FLOW-106 part 1). MCP `update_loan` takes `status` (`open`, `paid_off`, `closed`) and `closed_on`, returns `balance_left` for an ended loan, and its undo restores both; `list_loans` returns them and takes `include_closed`. A closed loan takes only payments dated on or before `closed_on`, from MCP (`loan closed`) and the app, whose match sheet no longer offers it for a later line. Closing a loan before a payment that is already attached is refused.
