An AI assistant that connects to Flow now learns the tools in one call. The connection greets it with a short brief (what Flow is, the four rules for writes), and a new read tool, get_started, returns the tools grouped by job with one line each and the common workflows step by step: filing a bank line, booking a balanced entry, a journal entry, binding a category to an account, reading the P&L and balances, and undoing a write. It lists only what the assistant's permissions allow.
