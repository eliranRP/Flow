Repo-wide deny-list check. `scripts/check-deny-list.mjs` scans every tracked text file against the `MERCURY_FIXTURE_DENYLIST` secret, not only the Mercury fixtures and tests, so docs, stories, e2e, connector rule files and subfolders are covered. An entry matches through punctuation, case, accents and line breaks, at any length. A hit prints only the file and line. CI runs it in the Mercury connector step; locally it skips without the secret.
The owner's first name is allowed (his call); the first run found no other denied name, which closes FLOW-902.
Exit codes: 0 clean or skipped, 1 hits, 2 secret missing in CI, 3 a tracked file could not be read. camelCase and run-together spellings of a multi-word entry match too.
