FLOW-974: each on-demand screen's own stylesheets load with its chunk. Fifteen whole files whose every rule only an on-demand screen can match (loans, loan detail, investment, invoices, project and company profit, add entry, line split, next month and more, and `setup.css`) moved from `ui.css` and `app.css` to `app/src/ui/lazy.css`, in the same order; a file that styles shared parts stays global. Every module the app loads with `import()` imports `lazy.css` first, so Vite loads it before the screen renders; `scripts/check-lazy-css.mjs` fails a module that does not (in `pr (types)`). Every story's computed styles, light and dark, match main's. Home's first load goes from 244.4 to 231.3 KB gzip, and `homeEntryGzipKB` from 246 to 236 (about 5 KB of room). A slow-network e2e check (`lazy-css.spec.ts`) shows three screens draw only after their styles arrive.
