FLOW-1273: the code a screen needs now loads with the screen, not after its data. The month forecast asks for its builder's chunk when its four reads go out and awaits the same fetch once they answer, and the read schemas' chunk is requested with the first read (at launch on Home with a session, and in `readyClient`, which every read passes), so they are there when the first answer is parsed. On the perf build with the stub backend the schemas' chunk was requested 30 to 70 ms after the first answer; it now goes out about 130 to 150 ms before it. Both stay lazy, out of Home's entry; nothing on any screen changes.
