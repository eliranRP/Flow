A project's next-month forecast is editable (decision 0186, board frames ProfitNextEdit, ProfitNextAdd, ProfitNextEdited, ProfitNextSearch, ProfitNextNoMatch, ProfitNextPace). A tap on a row opens its edit page: a new amount for November or on a pace, or הסרה מהצפי. הוספת קטגוריה לצפי adds a line of a category, picked in a sheet that suggests the project's own categories and can create one. Changed rows say "שינית · היה", removed rows list under the rows with החזרה, and חזרה לצפי של Flow drops every edit; every write has an undo. The profit page's card counts "<n> קבועים ו־<m> ממוצעים · ערכת <k>". New table `project_forecast_edits` with its RPCs, and MCP `get_project_forecast_edits`, `set_project_forecast_edit`, `remove_project_forecast_row`, `restore_project_forecast_row` and `reset_project_forecast`.
