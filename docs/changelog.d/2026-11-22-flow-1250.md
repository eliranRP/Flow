FLOW-1250, FLOW-1252 and FLOW-1253: three cuts in requests, with nothing a user sees changing. (1) An optimistic write (`useWrite` with `optimistic`) refetches each cached answer it changed once: a snapshot under one of the write's own keys is refetched by those keys, so it no longer gets a second request that cancels the first; a snapshot outside them is still refreshed. (2) Home on a month other than the current one no longer reads `missing_bills` or this month's `forecast_overrides_for`, since the late rows are drawn only on the current month; the current month reads both as before. (3) A cold Home sends `mcp_company_loan_currency` once, not twice: the month forecast reads the company's currency under the same key as Home's late-bills read (`companyCurrencyQueryOptions`), and a failed read still fails the forecast. Affects every screen whose writes pass `optimistic` (the unpaid list, the review queue, the transaction and project pages, categories, the member report, the JEV booking review) and Home.
