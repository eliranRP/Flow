FLOW-807 follow-up: a file-size guard. `scripts/check-file-size.mjs` fails when a code file goes over 800 lines or a test file (including pgTAP and e2e) over 1,200, and lists each offender. Local CI and the CI core check run it. Migrations and `database.types.ts` are exempt; `scripts/file-size-allow.txt` lists the files allowed over, each capped at its current size (today only the module 1 wireframe generator).
