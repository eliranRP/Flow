CI installs Playwright's system packages from the cache when it can. When the cached files cover every missing package, CI installs them with `apt-get install --no-download` and skips `apt-get update`, so a stalled Ubuntu mirror no longer holds up the job. Otherwise it downloads the rest. Every `apt-get` that reaches the mirror, including the `psql` install in `e2e` and `deploy`, is cut off after 100 seconds and tried once more against `archive.ubuntu.com`. The `psql` step skips apt when the runner already has `psql`.
