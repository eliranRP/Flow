A project's category drill-down works in any currency (Production QA). `list_project_category` read only ILS rows, so in a USD company the drill-down was empty while the project page showed the category's total. It now takes `p_currency` and returns `currency`: left out, it lists ILS when the category has ILS rows on the project, else the first other currency with rows. On the project page a category row in another currency opens its drill-down (`?currency=USD`), and the drill-down shows that currency.
