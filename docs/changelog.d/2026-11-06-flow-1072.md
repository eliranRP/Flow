Jev takes the property from the card's name (FLOW-1072, [0262](decisions/0262-jev-card-name-project.md)). When the paying card, or else the bank account, is named after exactly one active project ("<street> Utilities" for that street's property), Jev suggests that project, whatever the supplier's past lines say; the category is still Jev's own. Street kinds and purposes in a name never decide a match, and a number on both must agree. Lines Jev already tagged are not asked again.
