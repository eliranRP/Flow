Connector refreshes no longer clear each other's busy mark (FLOW-508). A Mercury or SUMIT run that outlived the 15-minute claim cleared the claim of a newer run when it finished, so Settings stopped showing "syncing" and a second run could start. A run now releases only the claim it took. While a refresh runs, Settings polls the status every 3 seconds as before; when the status read fails, it now waits longer between tries, up to a minute.
