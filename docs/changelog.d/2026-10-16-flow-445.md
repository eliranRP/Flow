The Projects tab is now a flat list of projects with each one's month cash, the finished ones under הסתיימו, and the overhead project last. A project's page has its own compact bar, a budget card (or "+ הוספת תקציב"), and a summary of its investment. The new-project sheet has a name, an optional type and an optional budget. The ⋯ menu edits the details, finishes or reactivates the project, and deletes it when it holds nothing.
