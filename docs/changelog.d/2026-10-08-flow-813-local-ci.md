The pre-push local CI is faster (FLOW-813, [TASKS](backlog/TASKS.md#flow-813)). `scripts/local-ci.sh` skips the typecheck, the builds, the app unit tests and Storybook when their inputs already passed in this clone, runs only the app tests related to the files changed since the last green commit when only `.ts`/`.tsx` sources changed, and runs the server tests beside the static checks. A push that leaves the app unchanged takes about 1 minute instead of 4–5. `--full` and `FLOW_LOCAL_CI_NO_SKIP=1` run everything, as main does.
