One company-name rule everywhere. The MCP `rename_company`, the `rename_company` RPC and a direct update of `companies.name` now accept and refuse the same names: trimmed of all whitespace (tabs, line breaks, no-break spaces), 2 to 100 characters counted as code points, and no control characters. A direct update that breaks the rule is refused with `23514`; an existing name is not re-checked when another column changes. Each rename and undo is tested for its `audit_log` row (FLOW-604).
