FLOW-1344: at most four database reads in flight at once. The app's Supabase client now queues REST and RPC requests beyond four (first in, first out; a request aborted while queued is dropped unsent), so a cold Home no longer wakes every database backend together on the memory-starved instance (FLOW-1300). Sign-in and token refresh, storage, edge functions and realtime are not queued, and nothing is retried.
