A push to a PR branch now runs only a quick check before it leaves: the scoped lint of the files the branch changes and the files that import them, under 20 seconds (`scripts/local-ci.sh --part quick`). The rest of the gate runs on GitHub in a new `pr` check (`.github/workflows/pr.yml`): the static checks, the related unit and Storybook tests in three shards, and the database checks when a migration or other `supabase/` file changes. `main` runs the full suite on every merge, and deploys every fifth merge as before (FLOW-832).
