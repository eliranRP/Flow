Jev phase 1, part 1: Jev labels new lines after each sync ([0123](decisions/0123-jev-after-sync.md)). A `flow-jev-tag` cron job runs `jev-tag` every 5 minutes, only when an enabled company has open lines without a suggestion and calls left today. Each company has a daily call cap (`company_integrations.daily_call_cap`, default 200) that a run reserves from in SQL before it calls Jev, and every run writes its calls and token counts to `jev_usage`. One run at a time holds a database lease. A line Jev failed on waits 6 hours (a day from the third failure) before it is sent again. New MCP read `get_jev_status`. Jev still never approves a line (FLOW-701).
