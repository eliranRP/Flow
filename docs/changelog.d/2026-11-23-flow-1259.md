FLOW-1259, FLOW-1260 and FLOW-1261: three cuts in work, with nothing a user sees changing except speed. (1) On the current month, Home starts the overrides read together with `missing_bills`, at mount, instead of after first paint, so the late row no longer waits up to about 1.5 s for browser idle time; the month forecast reads the same overrides under the same key, so no request is added, and the late row still draws once. (2) The Loans list builds each open loan's schedule once and passes it to its next payment and its late flag, and the summary card reads the same schedule, so a read builds each loan's schedule on its own terms once, where it was built three times.
