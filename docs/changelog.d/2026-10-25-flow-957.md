Notes and files on a transaction (FLOW-957). The transaction page has הערות וקבצים: Mercury's note with its attachments first, then the owner's notes with their files, oldest first, and a composer with a paperclip (a picture or a PDF, up to 20MB). Mercury's note comes in whole with every sync, its attachments are copied into Flow's private storage, and the note can be edited in Flow: saving sends it back to Mercury, and a Mercury key without write access keeps the edit in Flow and says so. The approval card has a row with the counts that opens לפני שמאשרים: Mercury's note, a photo, a file or a note, then לשמור ולאשר. The assistant reads the thread and adds, edits and removes notes (get_transaction_thread, add_transaction_note, edit_transaction_note, remove_transaction_note, remove_transaction_file), each with undo.
