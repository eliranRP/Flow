Import range for SUMIT and Mercury, server side (FLOW-505). Both syncs now skip documents and lines dated before the connector's import start and keep the rows already stored; until now only Mercury's complete runs did, and SUMIT ignored the setting. `sumit_status()` returns `import_from`. Moving the start earlier, or back to "from the start", makes Mercury's next sync read from the new start. The app control comes in a UI PR.
