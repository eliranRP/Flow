Import range for SUMIT and Mercury, server side (FLOW-505). A sync no longer writes a document or line dated before the connector's import start, and keeps the rows already stored (Mercury still rechecks their status); until now only Mercury's complete runs skipped them, and SUMIT ignored the setting. A SUMIT run whose documents are all before the start no longer reports an empty sweep. `sumit_status()` returns `import_from`. Moving the start earlier, or back to "from the start", makes Mercury's next sync read from the new start. The app control comes in a UI PR.
