**Perf (FLOW-1270, decision 0271):** the project page starts its month's lines and its utilities at mount, beside the project's own reads, instead of after them. The lines read no longer waits for the cash read (it asks for this month, in the company's books currency, which the server fills in), and the utilities read needs only the project id, so the page's reads that went out in a second and third wave now go out in the first. The next-month forecast card keeps waiting for the project's read, so it loads after the page's figures (the perf steward's measured choice, kept by decision 0271); touching a project's row now also starts the all-time project read and the forecast's reads, under the keys the page uses. The figures do not change.
