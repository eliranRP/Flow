Parent categories now have totals that include their sub-categories (FLOW-406, server part 2). The project page data gains one summed row per parent next to the per-category rows, which stay as they were, so every line still counts once. The monthly category view adds the parents with their months summed. The breakdown can group by parent, and searching by a parent category finds its sub-categories' lines too, with `category_exact` for the old match. In the MCP, `get_breakdown` takes `level: "parent"` and `search_expenses` takes `category_exact`. The screens follow in a later change.
