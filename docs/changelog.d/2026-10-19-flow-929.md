A new pgTAP test, `cross_company_sweep.test.sql` (FLOW-929), calls every database function the app and flow-mcp can call, read from the catalog, as another company's owner with the first company's ids as arguments, and again as a viewer of that company. It fails when a call changes any of the first company's rows, returns its ids, names or figures, or copies them into the caller's own company, and when a function is left uncalled, so a new function is covered without an edit. It found no leak or cross-company write. CONTRIBUTING's Database privileges section explains the sweep and its three small allowlists (decision 0193).
