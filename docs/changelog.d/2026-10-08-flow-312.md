MCP `get_project` now lists a line that reaches the project only through a part of a split by category (`split_line`), and each `transactions[]` row carries `parts_minor`, the sum of that line's parts on this project (0 when the line is split but none of its parts is on this project, null for an unsplit line). The `count` in `other_currencies` of `get_project` and `get_home` counts each bank line once, not once per part of a split line, per loan split part or per shared share; the amounts don't change (FLOW-312).
