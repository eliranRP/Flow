FLOW-1168: the server jobs get the end states they were missing (decision 0266), each flow a `defineMachine` table. Jev: a line Jev refuses as invalid (when it answered another line of the same company, at most 3 lines of a company a run) is not sent again until it or the company's projects or categories change (or 30 days pass), so it stops spending a call every day; the run's lease is renewed before each call and its budget counts from the lease; a run with nothing to tag no longer spends the 60-second gate. `get_jev_status` adds `lines_not_retried`. Push: a new-lines or weekly push no device took, with a try that can pass, is sent by the next run (the same new lines at most 3 times, the weekly one until 11:59 that Sunday); it is not sent again once a device confirmed it, and a send whose answer was lost can go out again within that bound, replaced on the device by its tag. A test push no device took, under the same rule, or with no device, does not count toward the five an hour, and an endpoint that is not a push service's is no longer deleted as gone. Invite email: a send Resend refused (a 4xx but 408, 409 and 429) no longer uses one of the invite's 3 emails, at most 3 times an invite. Thread purge: a name it cannot remove no longer stops it (a day for a name that fails the path rule, an hour for one Storage kept). `sync_bank` / `get_sync_status`: a done job says whether the pull read everything (`complete`), a retry says why (`reason`: `busy`, `rate_limited` with `retry_at`, `unknown`), and a job whose token was revoked mid-pull still ends. `docs/mcp/TOOLS.md` and `docs/tech/state-machines.md` are updated.
