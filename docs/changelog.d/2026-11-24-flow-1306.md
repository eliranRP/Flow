Database only (FLOW-1306, slice 5 of the [FLOW-1275 plan](../tech/flow-1275-server-side-math.md)): the loan schedule on a loan's own terms is now built in the database. `private.loan_schedule(p_terms jsonb)` is the TypeScript `buildLoanSchedule` ported line for line (every kind, rate changes and recasts, balloon and final adjustment, the exact annuity, interest half to even; refused terms raise the same error codes) and passes every shared loan-schedule vector. Two new tables, `loan_schedule_rows` and `loan_schedule_meta` (one row per loan: built, refused with its code, or none for a demand or closed loan), are kept current by triggers on `loans` and `loan_rates` in the same transaction, readable as the loans are and written only by the triggers; the migration backfills every loan. No existing read or table changes and the app does not read them yet (FLOW-1307, FLOW-1310).
