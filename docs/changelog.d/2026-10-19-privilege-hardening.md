Signed-in users can reach only what the app and the MCP connector use (decision 0193). The database no longer grants new tables, sequences or functions to signed-in or anonymous users by default; each migration grants what it needs. No table lets a client truncate it, add a trigger or reference it; forecast overrides are read-only outside the RPCs that write them; and a company can no longer be deleted with a raw REST call (a confirmed delete action comes later). Eleven RPCs no client calls (among them `company_pnl`, `save_split` and `set_supplier_settings`) are revoked; Home's and the project group's totals still read `company_pnl` through `get_dashboard` and `get_project_group`, which now run as definers. Two private tables get RLS like the rest. A new pgTAP file guards all of it, including an allowlist of the 185 definer RPCs a signed-in user may call.
