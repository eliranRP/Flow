The project page reads its month's lines once on a cold open. Without a company currency cached (a reload or a deep link), the lines used to start with no currency, then read both sides again when the currency landed. The page now asks for the company's books currency, which the server fills in, so the first read is the only one: two requests, not four. The rows are the same, and a company-currency change still refetches the lines (the currency sheet's list names them). The project's month profit page reads its lines under the same key when they are in the company's own currency, so a visit from the project page sends no new lines request.
