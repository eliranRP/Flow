Categories can now have one level of sub-categories (FLOW-406, server part 1). A category sits under a parent of the same kind; a loan category is never a parent or a sub-category, and a parent with sub-categories can't be deleted or merged away. Older category groups became parents of the same name, so nothing moves in the totals. The MCP has a new `set_category_parent` tool with undo, `create_category` and `create_categories` take a `parent_id`, and `list_categories` shows each category's parent and how many sub-categories it has. The screens follow in a later change.
