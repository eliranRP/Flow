A loan can name its own category for each part of its payments ([0127](decisions/0127-loan-part-categories.md), FLOW-106 part 2; supersedes 0088's fixed split categories). MCP `update_loan` takes `interest_category_id`, `escrow_category_id` and `principal_category_id` (null for the default) and undo restores them; `list_loans` returns them with names; `attach_loan_payment` and the app's split file each part under the loan's category. Interest and escrow need an expense category counted in the P&L and principal one kept out, so the owner can also correct a part into another category that fits; a category in use cannot flip sides of the P&L (`loan category is fixed`). FLOW-114's relaxed interest check is done.
