Project groups in the app (FLOW-406, screens proj-b, proj-b-2 and picker). The Projects tab lists each group as one row with its project count and summed profit, from `company_pnl.groups[]`, above the projects in no group. The row opens a new group page at `/projects/groups/:groupId` that lists the group's projects, active first, from the same dashboard read, so its figures match the row. A search lists matching projects flat and any group whose name matches. The project picker (review, transaction, split) lists a group's projects under its name, then שאר הפרויקטים; a search there also matches the group's name. Shared helpers in `app/src/project-groups.ts`, with unit tests and stories at 390, 320 and dark. No migration.
