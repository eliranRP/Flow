MCP hardening follow-ups (FLOW-205). The database now holds project, category, loan and company names to the MCP name rule: a new or renamed name with a control, invisible format or blank filler character is refused from the app too, a no-break or other wide space inside a name is stored as a plain space, and a name stored before the rule does not block other edits. The app's `create_category` and `upsert_project` clean a name the same way before checking it is taken. A SUMIT budget section name, which comes from outside, has its hidden characters dropped instead of refusing the sync. A refused MCP name says `name has an invisible or control character` instead of only `validation`. `scripts/check-edge-functions.sh` type-checks every edge function with its own `deno.json` in local CI and CI (a bare `deno check` cannot resolve their imports), which found and fixed a null check in `sumit-connect`. TOOLS.md lists the causes of `conflict` and the errors `sync_bank` itself returns.
