A project can carry its purchase price, after-repair value and today's value (`set_project_investment`, MCP `set_project_investment` with undo `project_investment`). `get_project` returns them in `investment` with rehab (all project costs but the loan parts and kept-out categories, on the cash basis), the open loan balance, forced equity and current equity. Each category has a rehab switch (`set_category_rehab`, MCP `set_category_rehab` with undo `category_rehab`) that adds it to rehab or takes it out ([FLOW-404](backlog/TASKS.md#flow-404), [0143](decisions/0143-project-investment.md)).
