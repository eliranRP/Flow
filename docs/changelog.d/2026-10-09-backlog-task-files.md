The backlog is one file per task, `docs/backlog/tasks/FLOW-<id>.md`, and `docs/backlog/TASKS.md` is an index generated from them by `node scripts/backlog-index.mjs` (the header, Lanes now, the priority order and the areas come from `tasks/index-source.md`). The index lists each task's id, title and type with a link to its file, and no status, so a status change edits only the task file and PRs stop colliding on TASKS.md. Local CI and CI fail when the index is out of date. Links to `TASKS.md#flow-<id>` still land on the task's row.
