A shared device keeps less of the last user. Unsaved split drafts in the tab are dropped on sign-out, an expired session or a user switch, and on a reload that finds a different user than the one who wrote them. A toast and its retry or undo action no longer outlive a user switch: the toast now sits inside the auth provider, so it remounts with the rest of the app (FLOW-605).

`create_company` follows the FLOW-604 company-name rule: the name is trimmed like JavaScript `trim()`, must be 2 to 100 characters and has no control characters. A new company can no longer get a name that a later MCP `undo` of a rename could not restore (FLOW-606).
