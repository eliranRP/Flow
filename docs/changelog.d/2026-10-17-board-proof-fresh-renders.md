board-proof now reads the fresh board renders from `--boards` or `FLOW_BOARD_PNG` and has no default folder, so a run can no longer compare against an old image. `scripts/board-render.mjs` makes those renders from the current design board (390x844, dpr 2, Ready and Light artboards), and `scripts/board-coverage.mjs` lists the board frames that no map names yet. `design/proof` has a frame map for every area of the app, and board PNGs and board HTML stay out of the repo.
