Gate-times report (FLOW-813 follow-up). Each local gate run now logs its diff kind (ui, server, migration, scripts, docs) and the seconds of each phase (lint-build, units, storybook, supabase, pgtap, e2e) in `gate-times.log`. `node scripts/gate-times.mjs [--since <time>]` prints the gate count, passes and median seconds per kind against the targets: UI under 3 minutes, server under 5, migration under 10.
