The recurring reads are faster, with the same results. A line with no project joins its party's closest charge in one set-based pass instead of one subquery per line, so recurring charges, a line's recurring state, the arrivals and changes, expected months, the schedule, missing bills and a line's charges all read faster. A project's waiting lines and a project category's lines read which lines are kept out of the P&L for the whole list at once instead of line by line. No screen or MCP tool changes.
