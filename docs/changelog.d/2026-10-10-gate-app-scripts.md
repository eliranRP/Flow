The pre-push gate no longer counts the whole scripts folder as an app input. Only the scripts the app's checks read or that pick what runs (listed in scripts/app-scripts.mjs: the bundle checks and build stamp, hosted-env, clip-check, serve-dist and the scope scripts) start the app's unit tests, Storybook and builds; a change to any other script, its tests included, runs the scripts suite, lint and typecheck. The typecheck still covers every script. A new test fails when the app's configs, tests, specs or the gate's build part reach a script the list leaves out.
