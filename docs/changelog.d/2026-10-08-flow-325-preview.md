Split preview and markers for the parts screen. `save_line_split` takes `p_preview` and returns the parts a save would store, in cents, without writing. Each saved part keeps the percent it was given and whether it is the rest, and `get_line_split` (and MCP `get_expense.line_split`) returns them as `percent` and `rest`. A repeated category and project is refused as `same category and project twice`, and a line of zero as `line amount is zero` (FLOW-325).
