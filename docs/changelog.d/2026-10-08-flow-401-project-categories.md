A project's categories are lighter (FLOW-401): each row shows just the name and the amount. Categories you put in one group, for example חשבונות, fold into one row that opens in place. In the month view a small amber up arrow marks a category above its usual month, a usual bill that has not come yet shows "—", and a category's page says what it usually costs a month. Settings → Categories → ⋯ → קבוצה sets the group.
