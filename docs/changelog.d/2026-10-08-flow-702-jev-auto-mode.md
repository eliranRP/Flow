Jev auto mode is safe to turn on ([0145](decisions/0145-jev-auto-mode.md)): it no longer fills a line flagged as a possible duplicate or spike unless Jev judged the flag unlikely, it fills income lines too, and every fill is recorded so the owner can take it back in one call while the line is still open. MCP adds `undo_jev_prefill`; `get_jev_status` adds `prefilled_today` and `prefilled_open`, and `get_jev_suggestions` adds `prefilled`.
