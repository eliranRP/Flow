FLOW-167 + FLOW-168: list row hints. On a report's category lines (/reports/lines), a line that a search found only by its description now shows the description as its title, up to three lines, so the matched word stays in view: a match far into a long description shows from two words before it, after "…", and screen readers get the whole description. A Latin description reads left to right and is no longer cut at its start, and the supplier and date move to the hint. On every list row with a " · " hint (month lines, the project and category pages, the reports and account drill-downs), the parts past the first that do not fit are now cut with "…" (two can be cut on one line) instead of dropping, so a long project name after the date no longer leaves only the date; a date or an amount is never cut, and a part with no room at all still drops.
