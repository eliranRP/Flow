FLOW-167 + FLOW-168: list row hints. On a report's category lines (/reports/lines), a line that a search found only by its description now shows the description as its title, wrapping so the matched word stays in view (a Latin description reads left to right and is no longer cut at its start), with the supplier and date in the hint. On every list row with a " · " hint (month lines, the project and category pages, the reports and account drill-downs), the first part that does not fit is now cut with "…" instead of dropping, so a long project name after the date no longer leaves only the date; a date or an amount is never cut, and a part with no room at all still drops.
