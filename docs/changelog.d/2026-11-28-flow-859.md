FLOW-859: undoing a line's recurring switch through the MCP (undo kind `line_recurring`) puts back the end date the switch cleared. Marking a charge recurring clears an end date that has passed (FLOW-1266); the undo used to put back only the switch, so an ended charge came back active. `set_payment_recurring` now also returns `prior_ends_on` (the end date it cleared, or null), and the undo leaves an end date set after the write. The FLOW-1266 tests also cover who may write an end date: a viewer, another company's line and another company's project are refused.
