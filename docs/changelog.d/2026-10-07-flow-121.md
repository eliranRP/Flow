Kept-out lines (FLOW-121). A line whose category is only a guess now counts in the P&L even when that category is kept out; it leaves the totals once the category is confirmed. Loan categories and a line's own P&L override work as before. `get_project` lists kept-out project income in `excluded_income_by_currency`, and `get_transaction` / MCP `get_expense` return `category_suggested`.
