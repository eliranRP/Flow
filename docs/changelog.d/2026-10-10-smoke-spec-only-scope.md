The pre-push gate no longer opens every story when a change edits only the Storybook layout, clip or secret specs. Many UI changes add a layout check to `app/e2e/storybook-layout.spec.ts`, and each one used to run the every-story check over all 1,377 stories (about 550 s of an 800 s smoke). Those specs still run, with the Storybook build. The every-story check now opens only the stories the change's other files reach, and skips itself when they reach none. A change to the Storybook setup, the every-story spec or its network guard still opens every story, and main still opens every story before each deploy.
