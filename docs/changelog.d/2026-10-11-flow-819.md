Removed the app code that only stories and tests still used: the old period bar, the checkbox, the loan balance list and project sheet, the `app/src/components` re-export shims, and about 30 helpers whose screens had moved on, with their stories, tests and CSS (FLOW-819). `node scripts/check-unused-app-code.mjs` now fails, in the pre-push gate and in `check (core)`, on any app module or export that only stories and tests use. A new rule for every agent: a change removes what it leaves unused (FLOW-820, CONTRIBUTING).

The pre-push gate's unit and Storybook vitest runs now start from the branch's last green push instead of the fork with main, so a fix-round push runs only the tests its new changes reach: 189 s instead of about 344 s in the measured case (FLOW-821).
