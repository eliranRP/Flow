An `auth` stop now clears only on a reconnect: a sync stamp that lands after the key was found bad, SUMIT's failure note and SUMIT's rejection note no longer clear or overwrite it. Per-slot claims are closed as designed (one Mercury run syncs every slot); SUMIT's resumable cursor is still open. `docs/tech/state-machines.md` (connector row) and `docs/tech/connector-contract.md` are updated.
