The Mercury test fixtures are now generated ([FLOW-903](../backlog/TASKS.md#flow-903)). `supabase/tests/connectors/mercury/generate_fixtures.ts` writes every file in `fixtures/`, `canonical-snapshot.json` included, from one seed: ids, times, amounts, balances and cursors come from a seeded random stream, and names are labels. The fixtures keep the same edge cases and canonical counts (100 posted lines, 70 imported, the same skip reasons). `pnpm fixtures:mercury` rebuilds them, even from an empty folder. `fixtures_test.ts` fails when a committed fixture differs from the generator output by one byte. The few test values pinned to fixture amounts follow the new data, and the fixtures README says how to rebuild them.
