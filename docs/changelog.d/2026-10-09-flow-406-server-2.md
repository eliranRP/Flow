Projects can now be put into groups (FLOW-406, server part 2). A project sits in at most one group, and a group's figures are the sum of its projects, so the company totals don't change. The dashboard data carries each group's totals and each project's group, and a new read gives one group with its projects for the drill-in. The MCP has `list_project_groups`, `get_project_group`, `create_project_group` and `set_project_group` (both writes with undo), and `list_projects` and `get_totals` return the groups. The screens follow in a later change.
