FLOW-205 (part 1): MCP `assign_expense` no longer demands a `project_id` for a line filed under a kept-out income category, which the database already allowed; leave it out or send null. Project, category and loan names sent through MCP (`create_project`, `create_category`, `create_projects`, `create_categories`, `add_loan`, `update_loan`) are refused as `validation` when they hold a control character or an invisible format character (zero-width space, bidi marks and controls, BOM, soft hyphen, tag characters, line separators, blank fillers), so two names can no longer look the same. ZWJ stays allowed for emoji.
