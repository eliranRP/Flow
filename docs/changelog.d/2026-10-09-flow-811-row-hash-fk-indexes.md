`scripts/prod-row-hash.sh` records a read-only row-hash baseline of the production tables (row count and an md5 of the rows per table, no values printed) and compares a later run with it, so a deploy that should not change data can be checked (runbook "Row-hash baseline"). Every foreign key now has an index that leads with its columns: 34 new indexes cover the 35 keys the database advisor listed, and a pgTAP test fails on a new foreign key without one (FLOW-811).
