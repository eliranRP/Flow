# FLOW-1253 · Perf: a cold Home reads the company's loan currency once, not twice
- **Type:** SMALL (perf) · **Status:** in-progress (#PR) · **Source:** the perf steward's 2026-11-22 [report](../../qa/perf/2026-11-22.md), cold Home.
- **Files:** `app/src/company-currency.ts`, `app/src/month-forecast-query.ts`, `app/src/forecast-skip.ts` (read only), their tests.

Since FLOW-1248 (#1242) a cold Home load sends `rpc/mcp_company_loan_currency` twice. `useLateBillsQuery` reads the company's currency through the keyed query `["company-currency", preview]` (`useCompanyCurrency`), while the month forecast calls `readStoredCurrency()` directly with no key, so the two never share an answer. Measured: building 77ebc62 against 5e4a1fcb and counting Home's cold-load requests, that second request is the only difference.

- [x] Export the query's options from `company-currency.ts` (`companyCurrencyQueryOptions(preview)`), and have the month forecast read them with `client.query`, so both share one key and one request. The hook keeps its signature.
- [x] A failed read still fails the forecast.
- [x] Test: Home's first view sends one `mcp_company_loan_currency` request; the test fails when the fix is reverted.

**Acceptance:** one `mcp_company_loan_currency` request on a cold Home load; the forecast still fails on a failed read; the tests pass.
