# FLOW-1014 · קבועים: the add action on the empty screen, and a plain label
- **Type:** SMALL UI · **Status:** ready · **Source:** UX rules review 2026-11-01 (`docs/runbooks/ux-rules-review.md`, rules in `.claude/skills/ux-ui-design-review-rules/`). Severity: Medium. From FLOW-1011.
- **Files:** `app/src/screens/recurring-screen.tsx` (`RecurringEmpty`, `RecurringAddLine`), `app/src/ui/recurring-list.tsx`.

- [ ] הוספת קבוע לצפי shows only under a populated list. The empty screen (no recurring charge yet) has no action, so a new owner can't add the first one there. Render `RecurringAddLine` in `RecurringEmpty`; not on the failed-load screen. Rule: onboarding-and-empty-states § 6 (1 icon + 1 primary action).
- [ ] The label says "לצפי" on a screen called קבועים, and the action is after every group, a long scroll one-handed. Label "הוספת קבוע"; place it under the card or as a + in the header, as Projects does. Rule: hierarchy-and-actions § 1.

**Acceptance:** the empty story shows the add action; it opens the same project sheet.
