# FLOW-1280 · Perf: cold Home sends its first two reads before the app's code arrives
- **Type:** MEDIUM (perf) · **Status:** ready · **Source:** decision [0271](../../decisions/0271-half-second-by-kept-data-and-one-wave.md), item 4: the main-thread profile of 2026-11-23 ([2026-11-23-main-thread.md](../../qa/perf/2026-11-23-main-thread.md)); FLOW-1274, cold Home timeline.
- **Files:** `app/index.html`, `app/src/home-early-reads.ts`, `app/src/use-books.ts`, `app/src/use-cash.ts`, `app/src/lib/company-header.ts`, `scripts/security-headers.mjs` (the inline script's hash), tests.

On the FLOW-804 phone the entry (about 203 KB gzipped JavaScript and 43 KB of CSS) finishes downloading at a median of 519 ms, and the first `/rest/v1` read leaves at a median of 715 ms (3 cold loads on the stub backend, [the profile](../../qa/perf/2026-11-23-main-thread.md#cold-home)). Between them the page evaluates the entry (about 60 ms), restores the session (`getSession`, the auth client's start-up) and runs `startHomeReads`. The read waits for all of the entry's code, though it needs only the saved session's token, the project URL and key, and today's date.

- [ ] An inline script in `index.html` (it already has one, and the build hashes every inline script into the CSP) reads the saved session from `localStorage` and, when the access token is still valid for another minute, sends `cash_months` and `get_dashboard` with the same headers and arguments `startHomeReads` uses, keeping the two promises on `window`.
- [ ] `startHomeReads` (or the two queries' `queryFn`) takes a kept promise when there is one, once, and otherwise sends the read as today. An expired token, a missing session, a changed company or a failed early read falls back to the normal path, so a failure never shows differently.
- [ ] Measure with `load-report` and the cold-Home loads in the perf profile: the first read should leave before the entry finishes (about 150 to 200 ms after navigation), and the data shows earlier by the time saved.
- [ ] Tests: the early read is used once; the fallbacks; the CSP hash; a read for another user's session is never used.

**Acceptance:** cold Home's first read leaves at least 300 ms earlier on the phone profile (the profile measured 0.5 s of room), every figure is the same, and the bundle stays within budget. Ask the owner first if the inline script needs a change to the CSP beyond its hash.
