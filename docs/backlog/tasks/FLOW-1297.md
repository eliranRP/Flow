# FLOW-1297 · Perf: Review's reads on load (the company id, the categories read twice, the overhead project's prefetch)
- **Type:** SMALL (perf) · **Status:** done (#1274) · **Source:** the 2026-11-24 daily report's diff review (load scope).
- **Files:** `app/src/use-review.ts`, `app/src/screens/jev-review.ts`, `app/src/prefetch-forecast.ts`, `app/src/use-review.test.tsx`, `app/src/screens/jev-review.test.ts`, `app/src/prefetch.test.tsx`.

Review's first read (and every later page and refetch) does more requests than it needs. Each item below was checked against the code before this task was written.

- [x] **Company id read.** `settleReviewJevScope` always sends `companies.select("id")`, even when Home's cached dashboard already names the company. Skip the read when the cached dashboard names it. The list does not carry the company (`list_review` omits `company_id`), so the list's answer cannot be a source. The direct visit (no cached dashboard) still reads it. Saving: 1 of Review's requests per visit with Home cached, and the same for each later page or refetch.
- [x] **Categories read twice.** With the Jev connector on, the queue read selects `categories(id,name,hidden)` again, beside the `list_categories` read the list starts. The queue uses the `list_categories` query's data (the key review-queue reads). The card shows the same names, hidden categories still left out. The card's own queue read, when no list read is in flight, keeps its table read. Saving: 1 request per Review visit with Jev on.
- [x] **Overhead project prefetch.** A project row's touch starts the project's own forecast reads without checking whether it is the company's overhead project. The page does not read them for the overhead project. Skip them when the cached overhead answer names this project; with no cached answer start them at once, as before, so no other row's reads wait for the overhead read. Saving: 3 requests per touch of the overhead project's row once its answer is cached.

**Acceptance:** each change is covered by a test that counts requests and fails without the fix; the gates pass; nothing Review shows changes.
