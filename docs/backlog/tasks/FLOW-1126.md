# FLOW-1126 · Member report forecast: the data, the calculation and MCP
- **Type:** MCP · **Status:** in-progress · **Depends on:** [FLOW-1125](FLOW-1125.md) (approved plan)
- **Source:** FLOW-1125's plan, option A approved by the owner on 2026-11-09, with rent and every cost type changing each year.
- **Files:** a new migration (+pgTAP), `packages/shared/src/member-projection.ts` (+test), `supabase/functions/flow-mcp/tools_member_share.ts` (+test), `docs/mcp/TOOLS.md`, a decision.

- [ ] `member_reports.config.projection`: the assumptions of FLOW-1125's table, the by-year changes and the category types, all optional (the defaults live in `packages/shared`), validated by `private.member_report_check` within FLOW-1125's bounds, with undo kind `member_report`.
- [ ] `get_member_report`, per property:
  - the latest full month's rent and the months rented (scheduled rent, so vacancy is counted once);
  - the last 12 months of `opex` by category after the first rent, with each category's type (or the type guessed from its name), excluding `debt_service` and `capex`;
  - its units;
  - each open loan's terms (debt service is principal and interest, no escrow).
- [ ] `computeMemberProjection(config, read, years)`: each year per property and for the portfolio (rent, vacancy, turnover, each cost type, maintenance, CapEx, NOI, debt service, cash flow, value, balances); the refinance in the chosen year (cash out, payment, DSCR); each member's part with their own loans repaid first (a loan on a property from its payoff, the company's own from the total, in proportion when short); the properties left out and why.
- [ ] MCP `get_member_projection` (year, member) and `set_member_report`'s `projection` part.
- **Acceptance:** pgTAP for the read and the validation; Vitest for the calculation, including a year with its own change, a loan paid off before year N, an interest-only loan, and a property with no rent; Deno for the tools.
