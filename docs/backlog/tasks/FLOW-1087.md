# FLOW-1087 · Charge page: the "לא צפוי ב<חודש>" switch stays disabled with no reason when the forecast fails to load
- **Type:** SMALL UI · **Status:** ready · **Depends on:** none
- **Source:** UX rules review 2026-11-07 (run 3, scope 925384f..ae9f7e4a: the v3 build).
- **Files:** app/src/screens/recurring-skip-month.tsx and its test.

**Finding:** The Toggle is disabled={disabled || (live && overrides.data == null)}, so a failed overrides query leaves it disabled for good, with no hint or retry.
**Rule:** feedback-and-states § 16 (do not disable without saying why).

- [ ] Disable only while the query is pending. On error, show the hint "לא הצלחנו לטעון את הצפי. נסו שוב" with a retry (overrides.refetch).

**Acceptance:** a failed overrides query shows the hint and retry; a test covers it.
