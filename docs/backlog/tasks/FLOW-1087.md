# FLOW-1087 · Charge page: the "לא צפוי ב<חודש>" switch stays disabled with no reason when the forecast fails to load
- **Type:** SMALL UI · **Status:** done (#1031) · **Depends on:** none
- **Source:** UX rules review 2026-11-07 (run 3, scope 925384f..ae9f7e4a: the v3 build).
- **Files:** app/src/screens/recurring-skip-month.tsx and its test.

**Finding:** The Toggle is disabled={disabled || (live && overrides.data == null)}, so a failed overrides query leaves it disabled for good, with no hint or retry.
**Rule:** feedback-and-states § 16 (do not disable without saying why).

- [x] Say why the switch is disabled: it stays disabled after a failed read, with the hint "לא הצלחנו לטעון את הצפי." and a נסו שוב link that reads it again (overrides.refetch).
  Done: the switch still waits while the forecast is unknown (pending or failed), since it cannot show a state it does not know; a failed read now says "לא הצלחנו לטעון את הצפי." in its hint (its aria-describedby) with a נסו שוב link that refetches. No story: the charge page's stories run on samples with no forecast read; the unit test covers the failed and retried read.

**Acceptance:** a failed overrides query shows the hint and retry; a test covers it.
