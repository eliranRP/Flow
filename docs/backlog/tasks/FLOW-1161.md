# FLOW-1161 · Setup wizard: a refused setting after the company exists, a silent skip-all, and controls live during a save

- **Source:** the state machine read of 2026-11-10 ([map](../../tech/state-machines.md), FLOW-1160). Read in the code, not run: check each still happens on `main` first.
- **Files:** `app/src/setup/steps.tsx`, `app/src/setup/skip-all.ts`, `app/src/setup/model.ts`, `app/src/setup/route-screens.tsx`, `app/src/screens/settings-screen.tsx`, their tests.

- [ ] Step 1: when `create_company` succeeds and a first setting is refused, the retry takes the existing-company path: the run's start (`run_started_at`, `flow_at`) is never stamped and the starter categories are not retried. With `?new=1` the retry creates a second company.
- [ ] Skip-all says nothing when `create_company` fails (`skip-all.ts`); the sheet stays open.
- [ ] Steps 3 and 5: דילוג and back stay live while the step saves.
- [ ] After skip-all the Settings entry still shows, and its link lands on Home (`settingsEntryVisible` ignores `skipped_all_at`).
- [ ] Settings counts the steps left as `5 - done` while the setup has 7 (`SETUP_TOTAL`).
- [ ] Step 2's "no bank" button records neither done nor skipped.
