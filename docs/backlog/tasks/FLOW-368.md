# FLOW-368 · Redesign: search with one סינון button, and opening from Home's icon
- **Type:** UI (design approved) · **Status:** ready · **Depends on:** [FLOW-363](FLOW-363.md), [FLOW-366](FLOW-366.md) (results are built like month lines) · **Related:** [FLOW-364](FLOW-364.md) (the icon in Home's band) · **Source:** the owner's approved redesign, handed off 2026-10-11; it replaces the chip row of [0146](../../decisions/0146-search-screen.md) and [0140](../../decisions/0140-search-filters.md). Design: [Design canvas](https://claude.ai/artifact/9grt9spjshVCxerYWrRXiD), page "Ready for dev", section "Search (חיפוש)" (boards: prototype from Home, results, filter sheet, filtered to a project, a project match on top, nothing found); rules on "Design guide", motion on "Flow & motion".
- **Files:** `app/src/screens/search.tsx`, `app/src/ui/search-field.tsx`, `app/src/ui/search-entry.tsx`, `app/src/ui/chip.tsx`, `app/src/ui/segmented-control.tsx`, `app/src/ui/match-text.tsx`, `app/src/ui/css/19-search-screen.css`, `app/src/ui/css/05-search-toast.css` (search blocks only), `app/src/screens/HomeScreen.tsx` (the icon's hand-off only), their stories and tests.
- [ ] Opens from the search icon in Home's band, and already filtered from a project's "כל התנועות" and a recurring charge's "לכל החיובים".
- [ ] Top (fixed): Back · a 44px rounded field (icon, placeholder "ספק, לקוח, פרויקט או סכום", × once there is text, accent border while typing) · "סינון" in accent with a count badge when filters are on. Active filters show under the field as small removable chips (tint, ×); nothing when none is on.
- [ ] Before typing: חיפושים אחרונים (the last 3, clock icon, fill the field) and שווה לבדוק (3 ready searches with a count: ממתינים לאישור, הכנסות החודש, the most active project).
- [ ] Results: a project whose name matches shows first as a shortcut row ("פרויקט · לדף הפרויקט"); one grey line "N תנועות · $total"; sticky month heads (newest first) with the month's total; rows: initial, payee, "dd/mm · project · category", amount with cents (income green); "ממתין לאישור" in accent as a third line where it applies. A row opens the transaction.
- [ ] Matches payee, customer, project, category and amount ("8940" finds $8,940.17).
- [ ] Filter sheet: סוג הכל / הוצאות / הכנסות; תקופה הכל / החודש / 3 חודשים; פרויקט chips (כל הפרויקטים + each project); רק ממתינים לאישור switch; ניקוי (text) and a full-width "הצגת N תנועות" that counts live.
- [ ] Nothing found: "לא מצאנו ״…״" and one line on what search looks at; with filters on, "חיפוש בלי הסינון".
- [ ] Motion (tokens; off under reduced motion): start ↔ results ↔ nothing found fade up 6px (220ms); result rows fade up 6px, 240ms, 30ms apart, only the first 8 staggered; each change of what is shown dips the list to 35% in 80ms and back in 180ms; a filter chip scales 0.9 → 1 (180ms), the × at 150ms; the badge pops 0.6 → 1.12 → 1 (240ms); the filter sheet uses the sheet motion.
- [ ] From Home: the icon becomes the field (scaleX 0.14 → 1 from its left edge, 300ms ease-enter) while the page fades in over Home (180ms); then the back arrow (+120ms), the placeholder (+140ms), סינון (+160ms) and the start content (+180ms); the keyboard opens with the field focused. Back is the reverse at exit timing, and Home underneath keeps its scroll. Opening already filtered uses the normal push from the left with results shown at once.
- [ ] Remove the old chip row, its dock and whatever only it used.
- [ ] Loading and empty: use the shared skeleton, empty state, inline spinner and sync strip of [FLOW-371](FLOW-371.md).
- **MCP:** `search_expenses` covers the query; add the project shortcut, the per-month totals and the live count for a filter set if they're missing, in TOOLS.md.
- **Acceptance:** stories of start, results with a project match, filtered, the filter sheet, nothing found with and without filters, at 320 and 393 with invented payees and amounts; a unit test that an amount without separators matches; a test that the count on "הצגת N תנועות" follows the filters; an e2e that Home → search → Back keeps Home's scroll; reduced motion skips the field growth; design review against the boards.
