# FLOW-1016 · Review lists: the בלי פרויקט count with pages left, and a loading line at the end
- **Type:** SMALL UI · **Status:** in-progress (#TBD) · **Source:** UX rules review 2026-11-01 (`docs/runbooks/ux-rules-review.md`, rules in `.claude/skills/ux-ui-design-review-rules/`). Severity: Medium. From FLOW-984.
- **Files:** `app/src/screens/review-lists.tsx` (`reviewAllSubtitle`), `review-shared.tsx` (`ReviewListEnd`), `review-queue.tsx`; the open-items read if the count comes from the server.

- [x] With pages left the subtitle drops "· N בלי פרויקט" until the last page loads, which a long queue may never reach. Return the count with the total from the server, or show "N+". Rule: feedback-and-states § 4, tables-and-responsive (counts are honest).
- [x] While the next page loads, the list end is an empty div. Show "טוענים עוד…" (`t-caption t-muted`, `role="status"`). When the queue runs out of loaded cards mid-flow, keep the card frame with a skeleton, not the full-screen loader. Rule: feedback-and-states § 2.

**Acceptance:** the paged stories show the missing count (or N+) and the loading line.

**Done:** no migration. With pages left the count is a floor from the loaded rows, "לפחות N בלי פרויקט" (hidden while it is 0); the exact count from the server stays open as a follow-up if the owner wants it. The card flow keeps its header with a skeleton card (`ReviewCardLoading`).
