# FLOW-441 · A project's "income changed" row opens a payment shown under another project
- **Type:** BUG · **Status:** ready · **Depends on:** — · **Source:** owner report 2026-10-11, with phone shots of a project page and the payment it opened. The shots hold real data, so they are not in the repo.
- **What happens:** On project A's page, the attention row reads "הכנסות שכירות עלה ב־29% · <amount> · בדרך כלל <amount>". A tap opens a rent payment whose page heads with project B ("מפוצל · 3 חלקים · לא נספר כאן"). Example with invented figures: one rent platform pays $3,000 a month, split across projects A, B and C. Project A's page shows the change row with the payer's whole $3,000 against $2,400, and the tap opens a payment headed by project B.
- **Why (from the code):** `recurring_changes` (`supabase/migrations/20261014091554_recurring_pace.sql`) groups lines by direction, party and currency, not by project. Each row's `project_id` is the party's most common project, `transaction_id` is the party's latest payment, and the amounts are the party's totals. `projectAttentionRows` (`app/src/screens/project-attention.ts`) keeps a row when its `project_id` matches, and `chargeChangeViews` (`app/src/forecast.ts`) links to `/transactions/<transaction_id>`. So for a split payer, the row can land on a project whose share it doesn't measure, and it opens a payment headed by another project.
- [ ] On a project page, a change row measures that project's own share of the payer's lines (amount now vs usual), or the row doesn't show there.
- [ ] Its tap opens the payment in a way that reads as this project's part (for example the transaction page scoped to the project, as the project lists already open it), not another project's header.
- [ ] Home keeps today's company-wide row.
- [ ] The MCP tool that reads `recurring_changes` returns the same per-project figures, listed in TOOLS.md if its shape changes.
- **Acceptance:** a pgTAP test with an invented payer split across two projects: each project's row has its own share and its own percent. A unit test that the project row's link opens on that project. A story of the project page with a split payer at 320 and 393.
