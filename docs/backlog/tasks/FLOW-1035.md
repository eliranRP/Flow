# FLOW-1035 · Month lines say which are recurring (Home v3 data)
- **Type:** SMALL CYCLE · **Status:** in-progress (#983) · **Depends on:** none · **Blocks:** FLOW-1036
- **Files:** a new migration (replaces `cash_month_lines`; appended to `supabase/migrations.lock`), a new pgTAP file in `supabase/tests/database/`, `packages/shared/src/cash.ts` and its test (the read returns JSON, so `database.types.ts` does not change).
- **Source:** [BUILD-PLAN §4](../../design/v3/BUILD-PLAN.md); the owner approved Home v3 on 2026-11-05 ([canvas](https://claude.ai/artifact/Rq2HmKi3E9WEQCFe9eXuyt), page Ready for dev). Home's new list splits the month into נותר לשלם, קבועים ששולמו and חד-פעמי, and a month line carries no link to the recurring schedule today.

- [x] Each row of `cash_month_lines` gains `recurring boolean`: true when the line belongs to a charge `recurring_schedule` lists this month (the same party, merge mapping and project the schedule's own live lines use, decision 0185), false otherwise. Reuse the schedule's matching, do not copy it.
- [x] `cashLinesSchema` takes it as `z.boolean().optional().catch(undefined)`, so an older server still parses.
- The migration's name takes the date prefix of main's latest migration and the current UTC time (README, Migrations); `git merge origin/main && node scripts/migration-ahead.mjs --rename` when a newer one merges first. Document the field in `docs/mcp/TOOLS.md` where `cash_month_lines` is described, if it is.
- **Acceptance:** pgTAP: a recurring party's line reads `recurring = true`, a one-off supplier's line `false`, a merged party's line `true`; the shared schema test parses rows with and without the field.
