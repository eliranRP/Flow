# FLOW-1095 · Home band at 320: the company name is cut to a few letters
- **Type:** SMALL UI · **Status:** in-progress (#TBD) · **Depends on:** none
- **Source:** UX rules review 2026-11-07 (run 3, scope 925384f..ae9f7e4a: the v3 build). The owner decided on 2026-11-07: below 360px move the least-used band icon into a ⋯ menu so the name gets about 96px or more; from 360px up nothing changes.
- **Files:** app/src/ui/css/07-band-home.css, app/src/screens/home-parts.tsx, home-parts.test.tsx, home-screen.stories.tsx.

**Finding:** At 320 four 44px icons leave the company name about 4 characters ("Acm…"), and the name is the way into החלפת עסק (shot home-current--light-320).

- [x] Owner to choose: keep a minimum width for the name (about 96px) by moving an icon into a menu, or stack the name above the icons under 360px. The owner chose the menu.
- [x] Under 360px a 44px ⋯ button ("עוד", `aria-haspopup="dialog"`) opens the app's `Sheet` with חיפוש and הגדרות וחשבון; the band keeps + and קבועים. The ⋯ takes the avatar's slot, so moving the avatar alone frees only 4px: search, the next least used, goes too (design log 2026-11-07-flow-1094.md says why). The name now reads "Acme Tes…" at 320 (over 96px).
- [x] From 360px up the row is unchanged and the ⋯ is not drawn.
- [x] Story: Screens/Routes "Home band, ⋯ menu at 320" (checks the ⋯ is 44px, the name is 96px or more, and the sheet opens from the keyboard); unit test: the ⋯ sheet holds both moved actions.

**Acceptance:** the owner's choice is built, with its stories and tests.
