# FLOW-1281 · Perf: stop reading layout in a screen's first commit
- **Type:** MEDIUM (perf) · **Status:** ready · **Source:** decision [0271](../../decisions/0271-half-second-by-kept-data-and-one-wave.md), item 4: the main-thread profile of 2026-11-23 ([2026-11-23-main-thread.md](../../qa/perf/2026-11-23-main-thread.md)); FLOW-1274, the top costs of Projects, the project page, Loans and Recurring.
- **Files:** `app/src/ui/amount.tsx`, `app/src/ui/screen-header.tsx`, `app/src/ui/back.tsx`, tests, stories for `Amount`.

The profile finds one pattern behind most of the "style, layout, paint" time (148 to 185 ms on the first visit to Projects, 203 ms on Recurring): code that reads layout while the page is still being built, which makes the browser lay out the page again and again.
- `Amount` with a `size` (the hero figures) fits itself in a layout effect: it reads `getComputedStyle` for its column and every ancestor up to `<html>` and measures a probe, once per figure, and again when fonts are ready (`readPad`: 46 ms on Projects, 41 ms on Loans, 25 ms on the project page; it is the top function of three screens).
- `safeTop()` in `screen-header.tsx` adds a probe to `<body>` and reads its style on every header mount (7 to 17 ms a visit).
- The `useLayoutEffect` in `back.tsx` reads `window.scrollY` in the first commit, which flushes the first layout (15 to 100 ms; 100 ms on Recurring).

- [ ] `Amount`: read each ancestor's padding once per column and share it between the figures in it (a cache that the ResizeObserver clears), or measure all figures in a column in one batch (all reads, then all writes).
- [ ] `safeTop`: read the safe area once per orientation instead of once per mount, with the same value.
- [ ] `back.tsx`: read `scrollY` only when there is a position to restore.
- [ ] No figure, size step or scroll position changes: the Amount stories, the clip check and the tap-response and project-open specs stay as they are. A UI lane's design reviewer signs off the Amount change (it is a shared component).
- [ ] Re-profile Projects, Loans, Recurring and the project page; report the new style, layout and paint time.

**Acceptance:** `readPad` and `safeTop` leave each screen's top 10 functions, and the first-visit main-thread time of Projects and Loans drops by at least 60 ms on the profile, with no pixel change.
