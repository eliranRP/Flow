- **Type:** MEDIUM (perf) · **Status:** in-progress (#1309) · **Source:** the 2026-11-26 daily report's diff review of #1299 (FLOW-1323).
- **Files:** `app/src/forecast-month.ts` (the writes no longer read after each write; `burstsOf`, `keptForecastOf`), `app/src/forecast-month-settle.ts` (new, a lazy chunk: what runs when a month's writes have settled), `app/src/forecast-month-screen.ts`, `app/src/kept-reads.ts` (`dropKeptReads`, `queueRead`), `app/src/signalled.ts` (new, moved from `screens/jev-deadline.ts`), `app/src/company-forecast-query.ts`, `app/src/month-forecast-query.ts`, `app/src/project-forecast-query.ts`, `screens/jev-review.ts`; tests `forecast-month-burst.test.tsx`, `forecast-read-abort.test.tsx`, `forecast-month-kept-figures.test.tsx`, `forecast-month-kept-drop.test.tsx`, `kept-reads.test.ts`. No migration.

The diff review of FLOW-1323 found five things. A skip read the month's overrides and its `month_forecast` answer after every write, so a burst of N swipes sent N rounds (25.7 KB each). No forecast read passed React Query's abort signal to Supabase, so a cancelled 102 KB `company_forecast` kept downloading. A skip deleted the kept `project_forecast` rows of every project and the kept company totals and never kept the patched answers again, so a cold start after a skip drew skeletons on Profit's card and the project cards; and the kept `answer` and `overrides` of the month stayed on the device when no screen held them (a skip from the project page), so a cold Home start drew the pre-skip forecast row. `dropKeptReads` opened a read transaction and then a read-write one on every tap. The Home entry sat 270 bytes under its budget.

- [ ] A burst of skips, resets and undos of a month reads its overrides and answer once, when the last write of the month's scope has settled; a refused write keeps FLOW-1308's failure handling.
- [ ] The forecast reads (`company_forecast` rows and totals, `month_forecast`, `project_forecast`) pass the abort signal, so a cancelled read stops its request.
- [ ] The patched company totals of the month and project forecasts are kept again once the server has accepted the burst, so a cold start draws the post-skip figures; the month's kept `answer` and `overrides` go at the skip, whether or not a screen holds them.
- [ ] `dropKeptReads` opens no transaction when the in-memory index shows no match, and one write when it does.
- [ ] What runs when a month's writes settle loads with the first skip (its own chunk); the Home entry does not grow (253,682 bytes gzip before).
