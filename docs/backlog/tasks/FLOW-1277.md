- [x] The splash: a 3-unit violet outline tile with a violet F; liquid rises inside it with a moving wavy surface; the F shows white where the liquid covers it; it ends as the app icon. The "Flow" wordmark (`Wordmark`, logo tone) fades in under it. Background `--color-bg`, light or dark; tile and liquid `--color-band` in both themes.
- [x] Timing: liquid 2400ms, wave 600ms x 4, wordmark 400ms from 2300ms, then a 160ms fade out (`--motion-toast-out`), about 2.9s. New motion tokens in the token file.
- [x] Plays once per page load (a cold start), never on a route change; never under `navigator.webdriver`. It is an overlay above the mounted app: `startHomeReads` and the first render do not wait. Only transform and opacity animate.
- [x] A tap anywhere (or a key) skips it with a quick fade. Reduced motion: the finished icon and wordmark for about 400ms, then the fade. `aria-hidden`, no focus taken.
- [x] The page colour before JS (`index.html`, light and dark); the manifest's `background_color` is `#F6F4FA` (dark mode is a known limit: the manifest takes one colour).
- [x] Within the bundle budget: the splash is a lazy chunk; the Home entry stays under its limit; the total limit moves 740 -> 745 KB with the reason in `bundle-budget.json`.
- [x] Tests (once per load, skipped under webdriver, tap skips, reduced motion, unmounts) and stories (start, mid-fill, done, dark). DESIGN-RULES §2.7 records the wave as the owner's decision of 2026-11-23.
