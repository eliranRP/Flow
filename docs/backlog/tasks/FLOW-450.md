# FLOW-450 · A property's returns: one read, with the transactions behind every figure
- **Type:** MCP · **Status:** claimed (dev lane, 2026-11-01, claude/compassionate-curie-mfpavd) · **Depends on:** [FLOW-446](FLOW-446.md) · **Related:** [FLOW-451](FLOW-451.md) (the screens) · **Source:** the owner approved the design on 2026-11-01 (concept A of three; Design canvas, page "Ready for dev", row "השקעה והלוואות v3"), from the book *Real Estate by the Numbers* (J Scott and D Meyer).
- **What:** a read that returns, for one property project and a period (default the last 12 months): the cash-flow statement (rent, operating expenses, NOI, loan payments, CapEx, cash flow, not counted), the four return sources (cash flow, principal paid, appreciation, tax savings) and the total return on the money in the deal, the three equity figures (equity today, forced equity, money in the deal), the metrics (cash-on-cash, cap rate, DSCR, cash flow per unit), and for every figure its parts and the transactions behind it.
- **Rules:** which line a category feeds comes from what Flow stores: income categories → rent; loan-part categories → loan payments; categories counted in rehab ([0143](../../decisions/0143-project-investment.md)) → CapEx; kept out of the P&L → not counted; the rest → operating expenses. No figure is guessed: a figure whose input is missing is null with the name of the missing input.
- **MCP:** `get_property_returns(project, from?, to?)` (read), listed in TOOLS.md; writes for any new input with an idempotency key, the write rate limit and undo.
- **Acceptance:** pgTAP for each figure on an invented property whose parts add up; company isolation (another company's project is `project not found`, the owner still reads their own); MCP test; TOOLS.md.
