# FLOW-1305 · Perf: shared test vectors, and the month forecast in one read
- **Type:** LARGE (perf) · **Status:** ready · **Source:** the FLOW-1275 [plan](../../tech/flow-1275-server-side-math.md), slice 2 (owner approval 2026-11-24).
- **Files:** `packages/shared/fixtures/vectors/month-forecast/*.json`, `packages/shared/src/vectors.test.ts`, `scripts/vectors-sql.mjs` and its test, the gate entry; a migration `<ts>_flow_1305_month_forecast.sql` (`private.month_forecast_build`, `public.month_forecast`), pgTAP `flow_1305_month_forecast.test.sql` and the generated `vectors_month_forecast.test.sql`; `app/src/month-forecast-query.ts`, `app/src/month-forecast-build.ts`, `app/src/kept-rules.ts`, tests.

Home's forecast row and the Forecast screen build `buildMonthForecast` from five reads (`expected_months(0)` 42 KB for Flow QA, `list_unpaid`, `forecast_overrides_for`, `company_forecast_edits_for` 8 KB, the currency). The math is 0.2 ms; the cost is five requests on one 4G line.

- [ ] The vectors: JSON `{ name, input, expected }` files run by vitest through the TypeScript builder and, through `scripts/vectors-sql.mjs` (with `--check` in the gate), by pgTAP through the SQL core. Start from `month-forecast.test.ts`'s cases, plus a split party, a handover, an ended charge, a quarter charge in and out of its month, each edit kind and an amount near 2^53.
- [ ] `private.month_forecast_build(p_input jsonb)`, immutable, the same result as `buildMonthForecast`; `public.month_forecast(p_month text)`, security invoker, gathering the existing reads. pgTAP: equal to the TypeScript build for the fixtures' companies; another company's member gets nothing.
- [ ] The app's month forecast query reads it; the builder's chunk goes if nothing else loads it; the kept rule follows the new answer. The old reads stay in the database (flow-mcp and older app versions read them).

**Acceptance:** the same figures and rows on Home and the Forecast screen; 1 request instead of 5; the answer's size, its database time and the sweep's Forecast and cold Home times reported before and after.
