# FLOW-1074 · The tab bar stays hidden after the keyboard closes
- **Type:** BUG · **Status:** in progress · **Depends on:** none
- **Source:** the owner's report with a Projects screenshot, 2026-11-06: the bottom navigation was gone and should show on every page.
- **Files:** `app/src/ui/keyboard-inset.ts`, its test.

- [x] The keyboard counts as open only while an editable field has focus, so a covered viewport with nothing focused never hides the tab bar.
- [x] The keyboard state is read again on focus changes, when the app comes back to the foreground (`visibilitychange`, `pageshow`) and on a window resize, not only on a visualViewport resize. iOS can close the keyboard without one, which left `data-kb="open"` and hid the tab bar on every page.
- **Acceptance:** unit tests for a covered screen with no focus, a blur with no resize, and a return to the foreground; `review-keyboard.spec.ts` still passes.
