# FLOW-1246 · A late row names its one bill or income
- **Type:** SMALL UI · **Status:** in-progress (#1238) · **Depends on:** none
- **Source:** the owner, 2026-11-21. On Home's "דורש טיפול" box two rows read alike: "חשבון אחד לא הגיע" (one late recurring expense) and "תנועה קבועה אחת לא הגיעה" (one late recurring income). The owner thought they were the same item; they were a utility bill and a rent payment. Owner's decision: when a row has exactly one late item, name it; when there are two or more, keep today's count wording exactly as now. Rule: hierarchy/copy — a row says what it is.
- **Files:** `app/src/forecast.ts` (`lateItemName`, `partyName`'s helper), `app/src/screens/attention-rows.tsx` (`missingName`, `missingIncomeName`; the named title in `count`), `app/src/screens/HomeScreen.tsx` and `app/src/screens/project-attention.tsx` (pass the names), `app/src/screens/home-screen.stories.tsx` (`HomeLateNamed`), `app/src/forecast.test.tsx` (the title and name tests), `docs/qa/CONTROLS.md` (the row's copy), `docs/design/log/2026-11-21-flow-1246.md`, `docs/changelog.d/2026-11-21-flow-1246.md`.

- [x] With exactly one late bill, its row reads "החשבון של {party} לא הגיע"; with exactly one late income, "התנועה הקבועה של {party} לא הגיעה". The party name is wrapped in `<bdi>`. The `short`, `tag`, `dismissKey` (`missing:N`) and `to` do not change; the tag "חשבון אחד" / "הכנסה אחת" still reads right beside the name.
- [x] Two or more late items keep today's count wording exactly ("N חשבונות לא הגיעו", "N תנועות קבועות לא הגיעו"). A single late item with no party name keeps today's wording too.
- [x] Home (`HomeScreen.tsx`) and the project page (`project-attention.tsx`) pass the name only when that direction's count is 1, from the same list the count comes from.
- [x] Tests: the name and the count wording, for one bill, one income, two or more, and one with no name (`forecast.test.tsx`). The e2e assertion on "2 חשבונות לא הגיעו" is a count and stays.
- [x] Story: `HomeLateNamed` shows one named bill and one named income; the count story `HomeLateRecurring` (three bills) stays as the 2+ state.
- [x] A named late row's title is 2 lines at most and always ends with its verb: the name is one line in `.ui-attn-name` that ends in "…" when long (owner's decision, 2026-11-21). The card grows to 2 lines; its list item has a finite cap so the dismiss fold animates. Story `HomeLateNamedLong` checks the cap, the line count and the ellipsis.
