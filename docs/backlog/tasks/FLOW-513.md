**קטגוריות (inner page, Back "הגדרות")**
- [ ] "איך התנועות מתחלקות ומה נספר ברווח"; a 2-way switch הוצאות / הכנסות; "+ קטגוריה חדשה" in accent.
- [ ] A card of categories, one line each: tag icon, name, one grey line with only what applies ("N תנועות · N תתי־קטגוריות · לא נספרת ברווח · נספרת בשיפוץ"), chevron → the category sheet.
- [ ] Card "מהלוואות": ריבית הלוואות, קרן הלוואות, נאמנות, fixed (no chevron), each with whether it counts in profit; "נוצרות מתשלומי ההלוואות. השם והספירה ברווח קבועים."
- [ ] Card "מוסתרות · N" at the end: "לא מופיעות בבחירת קטגוריה. התנועות שלהן נשארות."
- [ ] Category sheet: name and "הוצאה · N תנועות". First the transaction page's row: chart icon, "נספרת ב" and the result (רווח ותזרים / תזרים בלבד · הוצאה מהרווח / תזרים · שיפוץ, לא ברווח החודשי / לא נספרת), chevron → "איפה הקטגוריה נספרת" ("חל על כל N התנועות של <name>"), built like the transaction's sheet: נספרת ברווח, נספרת בתזרים ("כבוי רק להעברות בין החשבונות שלך"), and for expenses נספרת בשיפוץ. A single line can still override its category from the transaction page. Then rows: שינוי שם, קטגוריית אב, העברת התנועות לקטגוריה אחרת (N), הסתרה / החזרה לרשימה, מחיקה (signal; asks where the lines go). Every change: toast with ביטול.
- [ ] New category sheet: name, the kind (follows the switch), "נספרת ברווח. אפשר לשנות אחרי השמירה."; a duplicate name says so.

**החלפת עסק (sheet "העסקים שלך")**
- [ ] One row per business: initial tile, name, "<role> · פתוח עכשיו" on the current one, radio. Picking another switches and closes (toast).
- [ ] הזמנות, only when there is one: a tinted card "<business> · <inviter> הזמין אותך כצופה" with הצטרפות / דחייה.
- [ ] "+ עסק חדש" (dashed).

**Invitation screen (full screen, no tab bar; once, on the first sign-in after an invite; later it waits in החלפת עסק)**
- [ ] A soft band gradient; the business's initial tile pops in; "הוזמנת להצטרף", the business name 32/600, "<inviter> מזמין אותך לראות את הספרים של העסק ב־Flow" (+ "ולעבוד עליהם" for an editor). Blocks fade up one after another (80 to 300ms).
- [ ] Role card צופה / עורך with what it can do (green checks) and can't (grey ×). Facts card: הוזמנת על ידי (name · role), לכתובת (the invited email, LTR), בתוקף עד.
- [ ] One grey line: with a business of your own, that it stays as it is and switching lives in Settings; a new user sees "אם תדחו, אפשר לפתוח עסק משלכם ב־Flow."
- [ ] Fixed bottom: "הצטרפות כצופה / כעורך" (→ "מצטרפים…"), "אחר כך" (to Home; the invite stays in החלפת עסק), "דחיית ההזמנה" (signal).
- [ ] Joined: a check pops in, "הצטרפת ל־<business>", a line on where it now lives (or "זה העסק הראשון שלך ב־Flow"), "פתיחת <business>". Declined: "ההזמנה נדחתה", a line that the inviter will see it, ביטול הדחייה, המשך ל־Flow. Expired: "ההזמנה פגה", a tinted box with the date it ran out and to ask the owner for a new one; המשך ל־Flow.
- [ ] Loading and empty: use the shared skeleton, empty state, inline spinner and sync strip of [FLOW-371](FLOW-371.md).
- **MCP:** the category writes exist (`create_category`, `rename_category`, `set_category_parent`, `set_category_pnl`, `set_category_cash`, `set_category_rehab`, `hide_category`, `move_category_lines`, `delete_category`). Accept, decline and undo-decline are the invitee's own actions in the app (0167); if any is missing an RPC with an idempotency key and undo, add it. No new MCP write unless an invite action is offered to tokens.
- **Acceptance:** stories of קטגוריות (expenses, income, with hidden ones), the category sheet for an expense and a loan-part category, both sheets, החלפת עסק with and without an invite, and the invitation in each state (viewer, editor, new user, joined, declined, expired), at 320 and 393 with invented business and person names and example.com emails; a test that the loan-part rows have no chevron; a test that a duplicate category name keeps שמירה disabled; an e2e that "אחר כך" lands on Home and the invite shows in החלפת עסק; design review against the boards.
