# FLOW-1140 · A cold open and a screen's code: a neutral skeleton, not Home's or a blank page (plan)
- **Type:** PLAN FIRST · **Status:** ready · **Depends on:** —
- **Source:** the owner's app-wide skeleton ask, 2026-11-09 ([FLOW-1137](FLOW-1137.md)). The audit found two places outside any one screen:
  - A cold open of any signed-in route (settings, a loan, search, invites) draws Home's skeleton, with Home's band, while the session loads (`App.tsx`).
  - A full-screen route opened from a tab (search, invites, setup, line split, journal composer) shows a blank page until its code loads, because its `Suspense` fallback is null. Tab screens keep the previous screen up while they load, which is fine.
- **Files:** `app/src/App.tsx`, `app/src/screen-suspense.tsx`, a neutral skeleton in `app/src/ui/screen-skeletons.tsx` (after FLOW-1137 to FLOW-1139 land, so no build overlaps it).

- [ ] A plan the owner approves: which skeleton a cold open draws for a route that isn't Home, and what a full-screen route draws while its code loads.
