- [ ] Title "חיבור ל־AI", "MCP · העוזר שלכם עובד עם הספרים של Flow". Words: חיבור ל־AI, MCP, כתובת שרת MCP, קוד גישה, כותרת Authorization.
- [ ] Not connected, numbered steps: a card "מה אפשר לשאול" with three example prompts (a question, a check, a write); 1 · access: קריאה בלבד / קריאה וכתיבה, each with its line; 2 · a 4-way switch Claude Code · Claude.ai · ChatGPT · אחר that changes step 3; 3 · "Flow ייצור קוד גישה אישי. הוא מוצג פעם אחת, כמו סיסמה" and יצירת קוד, then the steps for the chosen assistant and the fields to paste, each with העתקה, monospace LTR (Claude Code: one field with the full `claude mcp add --scope user --transport http flow "<url>" --header "Authorization: Bearer <code>"` command; the others: כתובת שרת MCP and the Authorization header, with where to paste them); under the fields "הקוד מוצג פעם אחת ותקף ל־90 יום. אל תשתפו אותו."; 4 · a first question to ask; when the assistant's first call arrives the page turns to connected; סיום.
- [ ] Connected: "מחובר · <assistant>" with the access level, שימוש אחרון (time · N בקשות) and "הקוד בתוקף עד <date>"; one line that every assistant action is logged and can be undone; "יצירת קוד חדש" (outline; changing access = a new code) and ניתוק in the signal colour (toast with ביטול; the code stops working, the books stay).
