# FLOW-1252 · Perf: Home on another month does not read this month's late bills
- **Type:** SMALL (perf) · **Status:** ready · **Source:** the perf steward's 2026-11-22 [report](../../qa/perf/2026-11-22.md), diff review (load scope), row 3.
- **Files:** `app/src/screens/HomeScreen.tsx`, its tests.

`useLateBillsQuery(true, afterPaint)` reads `missing_bills` (about 20 KB, about 110 ms in the database) and this month's `forecast_overrides_for` even when Home opens on a past or future month, where the late rows are not drawn (they show only behind `isCurrent`). The `missing_bills` read there predates FLOW-1248; the overrides read came with it. A swipe from the current month already has both cached, so only a direct open of another month pays.

- [ ] Pass `isCurrent` as both arguments, so neither read runs on another month; the current month is unchanged.
- [ ] Tests: Home opened on another month sends neither request; the current month still reads both.

**Acceptance:** no `missing_bills` or `forecast_overrides_for` request on Home for another month; the tests pass.
