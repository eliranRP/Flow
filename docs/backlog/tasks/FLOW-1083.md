# FLOW-1083 · Reports: a small non-zero row shows "0% מהקבוצה"
- **Type:** SMALL UI · **Status:** ready · **Depends on:** none
- **Source:** UX rules review 2026-11-07 (run 3, scope 925384f..ae9f7e4a: the v3 build).
- **Files:** app/src/screens/reports-parts.tsx (barShare / reportHint), app/src/screens/reports-screen.test.tsx.

**Finding:** barShare floors the share, so a row that is a small part of its group says 0%.
**Rule:** feedback-and-states § 6 (say what is true), data-viz labels.

- [ ] When the amount is not zero and the floor gives 0, show "פחות מ־1%"; keep the bar at its minimum width. Add a test.

**Acceptance:** a row of $10 in a $10,000 group reads "פחות מ־1%"; a zero row still reads 0%.
