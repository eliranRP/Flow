# FLOW-1167 · Shared UI parts: holds and flags that can stay set (toast, sheet, list hold, swipes, disconnect, reload)
- **Type:** BUG · **Status:** ready · **Depends on:** [FLOW-1160](FLOW-1160.md)
- **Source:** the state machine read of 2026-11-10 ([map](../../tech/state-machines.md), FLOW-1160). Read in the code, not run: check each still happens on `main` first. UI lanes: no look changes.
- **Files:** `app/src/ui/toast.tsx`, `ui/sheet.tsx`, `ui/back.tsx`, `ui/change-sheet.tsx`, `ui/period-swipe.tsx`, `ui/swipe-row.tsx`, `app/src/list-hold.tsx`, `connection-undo.ts`, `connection.ts`, `sw-reload.ts`, `push.ts`, `txn-list-more.ts`, their tests.

- [x] Toast: a mouse press released outside the toast leaves `press` set and the dismiss timer paused; `hold` carries over to a replacement toast; the swipe path clears `press` without resuming.
- [ ] Sheet: `closing` is cleared only when `open` turns true or `onOpenChange` returns `false`, so a parent that ignores the close leaves every later close a no-op; a `onBeforeClose` that never settles blocks all closes.
- [ ] Change sheet: at `new`, the browser's Back lands on the summary and the sheet's back on the picker.
- [x] List hold: a pointer that never reports up keeps `press` set (no reset on blur or when the page is hidden).
- [x] `PeriodSwipe` drops a second finger without settling; `SwipeRow` stays open when `reveal` goes away, and its action stays live when `disabled` turns on.
- [x] Disconnect with undo: a rejected `onSent` leaves the entry for good; starting a disconnect on a key that is waiting drops the old entry's callbacks.
- [x] Online state: a reachability check started for one offline event can set online after a later one.
- [x] New version reload: the loop guard clears `pending` first, so the reload is dropped.
- [ ] Push subscribe: a throw in the controller step reports `worker-timeout`, and the outer limit always reports the `subscribe` step.
- [x] `useTxnListMore` replaces the entry while an earlier load still writes the old one.

**Acceptance:** each box with a test; the toast, the sheet and the disconnect entry are tables per decision 0266.
