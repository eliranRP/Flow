# FLOW-1143 · Utility refunds: exact matches only, and no suggestions
- **Type:** SMALL UI (owner's decision) · **Status:** done (#1107) · **Depends on:** [FLOW-1142](FLOW-1142.md)
- **Source:** the owner, 2026-11-09, on the live screen: "The new screen is too complicated, it should be easy to use and understand; suggest only exact amounts and the same categories." Then they picked "count exact, no suggestions".
- **Files:** a new migration (+pgTAP) that redefines `private.utility_refund_rows` and what reads the suggestions; decision 0265 (amended); `docs/mcp/TOOLS.md` and the MCP descriptions; `app/src/screens/utility-refunds-*`, `utility-refund-view.ts`, `attention-rows.tsx`, the schema, the samples, stories and tests; the design log; changelog fragments.

- [x] A bill counts as refunded by itself only when a money-in payment has its exact amount and is filed to the bill's own category. Several bills of one month and one category still count when the sum is exact.
- [x] Nothing is suggested: no rent-plus-bills rule, no other-category or no-project guesses. Everything else is לא הוחזר after 30 days.
- [x] The owner's own answers keep working: picking the payment (a payment in another category shows the fix and להשאיר), ראיתי, החברה משלמת תמיד, the refile and every undo.
- [x] The screen loses the suggestion cards and the הכול / לבדיקה / לא הוחזרו control. Home's row reads only "N חשבונות לא הוחזרו · $X".
- **Acceptance:** pgTAP for the exact rule (an exact amount in another category is neither counted nor suggested); app tests and stories updated, and what the change leaves unused removed.
