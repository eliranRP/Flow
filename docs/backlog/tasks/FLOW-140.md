**Company profit (from Home's רווח החודש; Back "בית")**
- [ ] Title רווח 32/600, "<month year> · עד היום", profit 34/400 (a loss in the signal colour with U+2212), one grey line "מתחילת השנה +$X".
- [ ] Card: two thin bars scaled to the larger: הכנסות (amount green) and הוצאות שנספרות ברווח. Nothing else.
- [ ] Chips: לפי פרויקט (default) · לפי קטגוריה · לפי תאריך · לפי סכום. Project: one row per project, no heads (name, "N תנועות", profit; a loss in the signal colour), largest first, כללי = no project; a row opens that project's profit. Category: one row per category ("N תנועות · N פרויקטים", total; income green, expenses plain, never red); a tap opens the row in place to show its lines, a second tap closes it. Date and amount: the lines as on month lines; a line opens the transaction.
- [ ] Bottom, small: what is not counted in profit (FLOW-440's row and list), and "נספר לפי תאריך תשלום · שינוי" → the basis sheet.

**Project profit (pushed from the left; Back "רווח")**
- [ ] Title רווח, "<project> · מאז <month> · N חודשים", profit since the start 34/400.
- [ ] Card: הכנסות (green) / הוצאות שנספרות ברווח / חלק בהוצאות הכלליות / רווח אחרי הוצאות כלליות (17/500), one line on how the share is split ([0021](../../decisions/0021-shared-costs-and-overhead.md), [0022](../../decisions/0022-after-overhead-starts-off.md), [0117](../../decisions/0117-overhead-project-weights.md); the minor-unit share from [0147](../../decisions/0147-company-currency.md)).
- [ ] Chips: לפי חודש (default) · לפי קטגוריה. Month: one row per month, newest first ("<month> · עד היום" for the open one), "הכנסות $X · הוצאות $Y", the month's profit → the project month page. Category: expenses since the start, one row per category with "% מההוצאות · N תנועות" and a 4px bar (band purple on #2E2740, scaled to the largest). Year heads in the month list follow FLOW-443's plan once approved.

**Project month (pushed over project profit; Back "רווח <project>")**
- [ ] Title "רווח <month>", "<project> · עד היום, dd/mm · N תנועות" or "חודש סגור". The same four-row card for the month (the month's share of general expenses). Chips: לפי תאריך (default) · לפי סכום · לפי קטגוריה (no project chip). Back carries the project's name, which closes FLOW-444 if it hasn't shipped first.

**Basis sheet (רווח ותזרים לפי)**
- [ ] תאריך תשלום / תאריך חשבונית, one line each; "חל על כל החברה"; toast on change. The same setting as Settings (0170).
- **Owner's answer (2026-10-12):** per category. Each category's נספר ב setting decides: רווח ותזרים counts its lines in monthly profit, רק תזרים keeps them out of profit and adds them to the property's השקעה. Renovation categories (materials, labour on a flip) default to רק תזרים, so a flip under renovation shows only its loan interest in the month's profit. The project figures read the category setting; no flip-specific rule.
- [ ] Loading and empty: use the shared skeleton, empty state, inline spinner and sync strip of [FLOW-371](FLOW-371.md).
