# FLOW-1238 · Bug: a sheet floats mid-screen after coming back from another app
- **Type:** BUG · **Status:** claimed · **Source:** the owner, 2026-11-20: Home's ⋯ sheet opened mid-screen, with the page showing under it, after returning to the app from another one.
- **Files:** `app/src/ui/keyboard-inset.ts`, `app/src/ui/keyboard-inset.test.tsx`.

Back from the background, iOS can report a visual viewport shorter than the window with no keyboard up. `--kb` (the sheet's lift above the keyboard, FLOW-1024) took that gap as a keyboard, so every sheet sat that high above the bottom. `data-kb` already needed a focused field (FLOW-1074); `--kb` did not.

- [x] `--kb` is 0 unless an editable field has focus.
- [x] A test: a short viewport with no focused field gives `--kb: 0px`.

**Acceptance:** with no field focused, a sheet always sits on the screen's bottom.
