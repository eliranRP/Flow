# FLOW-1350 · Perf: the setup check remembers the server's answer, so a cold Home stops asking every time
- **Type:** SMALL (perf) · **Status:** ready · **Source:** the [2026-11-28 daily report](../../qa/perf/2026-11-28.md), diff review (load scope, row 5).
- **Files:** `app/src/setup/gate.ts`, `app/src/setup/storage.ts`, their tests.

Since FLOW-1343 a phone with a final local setup flag (finished, skipped or resumed) makes no setup read. An owner whose phone has none (finished on another device, cleared storage, never started a run) reads `setup_states` on every cold Home, because the server's "no" lasts only one page load (`staleTime: Infinity`). It is a tail read. The daily sweep's fresh browser is such a phone, so this is the 18th request on its cold Home (the [2026-11-28 report](../../qa/perf/2026-11-28.md), section 3).

- [ ] Keep the server's final flags (or a "checked, nothing to resume" mark) on the device, per user and company; a later setup start on this phone clears it.
- [ ] Tests: the second cold Home makes no setup read; a resumable run on the server is still found on a phone that never saw it.

**Acceptance:** one setup read per user and company per phone, not per cold Home.
