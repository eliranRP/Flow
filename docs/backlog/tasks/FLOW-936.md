# FLOW-936 · The notification switches answer at once, and this device's row catches up without a relaunch
- **Type:** BUG · **Status:** in-progress (lane, 2026-10-20, fix/notify-toggles-snappy) · **Depends on:** [FLOW-516](FLOW-516.md). **Source:** Owner report 2026-10-20 (iPhone Home Screen app): notifications work, but the on/off switches are laggy, and the app had to be closed a few times before they were right.
- **Files:** `app/src/screens/notifications-screen.tsx`, `app/src/screens/notifications-screen-live.test.tsx`, `app/src/push.ts`, `app/src/push.test.ts`.
- [x] The three shared switches waited for `set_notification_prefs` before they moved, and every other switch was disabled meanwhile. A tap now flips the switch at once and saves in the background; a failed save puts that switch back with "לא הצלחנו לשמור.". The other switches stay free, and quick taps on one switch send one save at a time and then only the latest value, so it ends where the last tap left it. The undo toast still turns it back.
- [x] This device's state was read only when the screen opened. A first open while the service worker still installed read "no-worker", and a permission changed in the iOS Settings app stayed stale, until the screen opened again. It is now read again when the worker takes control (`controllerchange`) and when the app comes back to the front, here and on the review card.
