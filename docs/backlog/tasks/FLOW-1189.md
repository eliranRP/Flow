- **Type:** SMALL UI (perf) · **Status:** claimed (perf steward, 2026-11-13, flow-1189-home-lines-20) · **Source:** the owner's answer of 2026-11-13 to the question card "Home reads 200 + 200 lines for its money-in / money-out lists below the fold. A smaller first page would load faster but changes how many lines Home lists before the 'more' row. What do you want?": "First 20, more on tap: Shortest lists; the 'more' row appears sooner."
- **Files:** `app/src/use-cash.ts` (the page size argument), `app/src/screens/HomeScreen.tsx` (20 a side, the more row's href), `app/src/screens/home-activity.tsx` (the current month's more row), `app/src/ui/css/43-home.css` (the foot's gap), `app/src/screens/home-cash.test.tsx`.

Home's two line lists (נכנס and יצא, the current month's one-off group and a past month's whole list) read 200 lines a side on the first call. The owner chose 20 a side on the first screen, and the rest on tap.

- [x] `useCashLinesQuery` takes a page size (default 200, part of the query key). The month's lines screen keeps 200.
- [x] Home reads 20 a side, and reads no further page itself.
- [x] The "more" row opens the month's lines screen on the side that runs past its first page (out first). That screen loads every page with its own 200, so the rest comes from it. Home does not load the next pages in place, so the next-page size does not matter on Home.
- [x] The current month had no "more" row, so lines past the 20th were hidden. It now shows "כל התנועות" beside "כל הקבועים" when a side has more.
- [x] Home's after-paint gate (FLOW-1019) is unchanged.
- [x] Every other caller of `useCashLinesQuery` (the month's lines screen) keeps 200.

**Acceptance:** Home asks `p_limit` 20 for each side, and no further page; the month's lines screen still asks 200; a list with more than 20 lines on a side shows the "more" row that opens the month's lines (on the current month too); the new tests fail on main; the bundle stays within the budget (Home entry at most 248 KB gzip, all JavaScript at most 740 KB).
