# FLOW-1254 · Home's late row waits for the month's skips before it draws
- **Type:** SMALL UI · **Status:** ready · **Depends on:** FLOW-1248
- **Source:** UX rules review 2026-11-22 (scope c090b96a..9ee732a3): #1242 (FLOW-1248) reads the late list at once but the charges taken out of this month only after first paint (`app/src/screens/HomeScreen.tsx`, `useLateBillsQuery(isCurrent, isCurrent && afterPaint)`), and `useLateBillsQuery` (`app/src/forecast-skip.ts`) returns the whole list until the overrides land. A person with a skipped late charge first sees "N חשבונות לא הגיעו", then the row changes to a named row or leaves, which moves the attention box and what is under it. Severity: Medium. Rule: feedback-and-states § 2 and § 4 (a loading state should not show content that is about to change); the owner's FLOW-1220 decision (nothing moves under a finger).
- **Files:** `app/src/forecast-skip.ts` (`useLateBillsQuery`), `app/src/screens/HomeScreen.tsx`, `app/src/forecast-skip.test.tsx`.

- [ ] While the overrides read is still to come or pending (it is enabled later, after first paint), the late list is not yet known (`data` undefined), so no late row draws. Once the overrides land, the filtered list draws. If the overrides read fails, the whole list draws (an error never hides an alert, FLOW-1248). If the overrides never get enabled on this screen, the late rows must still draw: do not wait on a read that cannot start.
- [ ] Tests: pending overrides give no late list; landed overrides give the filtered list; a failed overrides read gives the whole list.

**Acceptance:** each box done; Home's late row draws once, at its final count and name.
