# FLOW-1164 · Editors and sheets: move the saves that can run twice onto `saveFlow`
- **Type:** BUG · **Status:** in-progress (#1128) · **Depends on:** [FLOW-1160](FLOW-1160.md)
- **Source:** the state machine read of 2026-11-10 ([map](../../tech/state-machines.md), FLOW-1160). Read in the code, not run: check each still happens on `main` first. UI lanes: no look changes.
- **Files:** `app/src/screens/line-split-editor.tsx`, `journal-composer-screen.tsx`, `loan-detail-screen.tsx`, `loan-match-row.tsx`, `forecast-screen.tsx`, `recurring-charge-screen.tsx`, `unpaid-actions.ts`, `assistant-setup.tsx`, `jev-connector-scope.ts`, their tests.

- [x] The line split editor and the journal composer clear `saving` before the reads are refreshed and the page leaves, so a second write is not blocked for that wait; their retry toasts run the failing render's closure (old payload, old `busy`).
- [x] The loan page's close guard is one boolean cleared by whichever save ends first.
- [ ] The loan match's edit and its undo's rematch check no write in flight.
- [ ] A forecast move shows its toast before the write, and the write is sent only from this screen's effect: a screen that unmounts first never sends it. The fold timer is not cleared on unmount.
- [ ] The recurring charge page's ignore, restore and answer are raw awaits with no guard, and their local overrides are never cleared after the server answers.
- [x] Unpaid's mark, link and dismiss have no pending guard.
- [x] A failed revoke after minting an assistant key is silent.
- [ ] `JevScopePhase`: `off` with a bound scope can be built, and after a miss a scope binds while the phase stays `miss`.

**Acceptance:** each box with a test that sends the second tap; each flow is a table per decision 0266 and its row in the map moves to "Explicit machines".

**In #1125:** the journal composer and the line split editor hold their save in `saveFlow` until the page has left, and their retry runs the latest render's save; the loan page's close guard is a count; unpaid sends one write per action at a time; a failed revoke after a mint says so. **Left:** the loan match's rematch (no reachable case found); the forecast move (its write is sent by the fold timer even after the screen closes, so the gap as written is not real; the timer still is not cleared on unmount); the recurring charge page's local overrides that never clear (needs keyed overrides); `JevScopePhase` (changing it changes what the card relies on: a design call). **Found:** six loan sheets return nothing from `onOpenChange(false)` during a save without passing `busy` to the Sheet (`loan-kind-sheet.tsx`, `loan-detail-screen.tsx` twice, `loan-detail-sheets.tsx`, `loan-closing-paid-sheet.tsx`, `loan-close-sheet.tsx`, `loan-rate-sheet.tsx`); if that save fails, later closes do nothing. Pass `busy`.

**In #1128:** the six loan sheets return `false` from `onOpenChange` when they refuse a close during a save, so a failed save no longer leaves later closes doing nothing. (The loan page's delete confirm already passes `busy`.)
