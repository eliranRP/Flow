# FLOW-1268 · UI: a small hint while a screen shows kept figures and fresh ones load
- **Type:** SMALL UI · **Status:** ready (a UI lane, design session first; FLOW-1267 and FLOW-1270 to FLOW-1272 have merged) · **Source:** decision [0271](../../decisions/0271-half-second-by-kept-data-and-one-wave.md) (owner, 2026-11-23); the perf steward's split of 2026-11-23.
- **Files:** `app/src/ui/` (a new shared hint component and its story), `app/src/ui/top-band.tsx` (`TopBand`, where the hint sits) and `app/src/ui/band-states.tsx`, the screens that pass it (`HomeScreen.tsx`, `projects-screen.tsx`, `project-detail-screen.tsx`, `loans-screen.tsx`, `recurring-screen.tsx`, `company-profit-screen.tsx`, `review-screen.tsx`, `forecast-screen.tsx`), `app/src/ui/css/` (one block), a design log entry.

Decision 0271, item 1: the owner chose "Yes, with a small hint" (2026-11-23). While a screen draws kept data (FLOW-1267) and its fresh read is in flight, a small, quiet hint says the figures are updating; when the fresh data lands it goes away and the figures change in place.

- [ ] A UI lane builds it. Design session with the design reviewer (DESIGN-TEAM); build the option the designer recommends, in the five-token styles; the design lead signs off. It must not move the layout when it appears or goes. Pixel check at 320 and 393 px, dark and light.
- [ ] The screens' headers are shared with FLOW-1270 to FLOW-1272: the claim names the functions it changes in each screen file.
- [ ] One shared component with a story per state (updating, updated). Decide with the designer what shows when the fresh read fails (the kept figures stay; today's error handling decides the rest).
- [ ] Give it a stable marker (for example `data-kept="updating"`) for tests; the sweep's "fresh data shown" comes from the reads, not from this marker (0271).
- [ ] Design log entry; tests for showing and hiding it.

**Acceptance:** the hint shows only while kept figures are on screen and a fresh read is in flight, on every main screen, with its stories and design log entry.
