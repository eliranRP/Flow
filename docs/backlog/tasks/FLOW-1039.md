# FLOW-1039 · Pull to refresh on every screen (ld-07)
- **Type:** SMALL UI · **Status:** done (#977) · **Depends on:** — · **Source:** the owner, 2026-11-05: pulling down on a screen does nothing in the Home Screen app (iOS gives a standalone web app no pull to refresh); add a loading spinner on pull, as other banking apps do. Design: DESIGN-RULES "ld-07 Pull to refresh" (no component yet); tech plan: pull to refresh does what opening the app does, with a 30-minute floor on a bank sync.
- **Files:** a new `app/src/ui/pull-refresh.tsx` and its story and test, a new CSS file under `app/src/ui/css/`, the app shell that wraps every routed screen (one place, not per screen), `app/src/ui/index.ts`, `docs/design/DESIGN-RULES.md` (the ld-07 row and the component), a design log entry.

- [x] Pulling down from the top of any routed screen (the scroller at scroll top 0) shows a spinner (`.ui-spinner`, `--motion-spin`) that follows the finger with resistance; past a threshold (about 64px) a release refreshes, before it springs back with nothing done.
- [x] A refresh re-reads every active query (TanStack Query); the spinner stays until the reads settle (at least 400ms), then collapses. A failed read shows the app's usual error toast once. Opening the app starts no bank sync today (the bank syncs run on the server's schedule and from the connection screens), so a pull starts none either; whether a pull should ask for one is [FLOW-1040](FLOW-1040.md).
- [x] Never starts inside an open sheet, dialog or a horizontally swiped row, from a scrolled list, or during a period or card swipe or the edge-back gesture; native overscroll does not double it. Works by touch (iPhone) and does nothing with a mouse wheel.
- [x] `prefers-reduced-motion`: no follow and no spring, the spinner fades in place. The spinner has an accessible busy label ("מרענן").
- **Acceptance:** a unit test for the threshold, cancel, and no start when not at the top or inside a sheet; a story in both themes at 320 and 393 px (idle, pulling, refreshing); a design log entry.
