# FLOW-1130 · Utility refunds: the data, the match and MCP
- **Type:** MCP · **Status:** ready · **Depends on:** [FLOW-1129](FLOW-1129.md)
- **Source:** FLOW-1129's plan, approved by the owner on 2026-11-09.
- **Files:** a new migration (+pgTAP), `supabase/functions/flow-mcp/tools_utility_refunds.ts` (+test), `docs/mcp/TOOLS.md`, the regenerated DB types (`pnpm db:types:check`), a decision, a changelog fragment.

- [ ] `utility_payers` and `utility_refund_answers`, RLS on, no client grant.
- [ ] The utilities found from the lines (the חשבונות categories, the card-name match) plus the ones the owner added; each tenant-paid by default.
- [ ] The match on read: the window (one month before the bill to an as-of date the tests pass in, never `now()`), the property, the three amounts within one unit of the currency (100 minor units), one payment per bill. Auto only when the amount and the bill's category match; otherwise a suggestion. לא הוחזר after 30 days. A month with no rent is flagged.
- [ ] `list_utility_refunds`, `count_utility_refunds`, `set_utility_payer`, `answer_utility_refund` (matched, rejected, seen, or null to take it back), `mark_utility_refunds_seen` (a property's open לא הוחזר bills at once), and the refile for the one-tap fix (splitting off the bill's part of a rent payment).
- [ ] MCP: `list_utility_refunds`, `count_utility_refunds`, `set_utility_payer`, `answer_utility_refund`, `mark_utility_refunds_seen`, `refile_utility_refund`, with idempotency, the write rate limit and undo.
- **Acceptance:** pgTAP for each amount rule, the window, the category rule for auto, a rejected pair, a company-paid utility, a seen bill, a month with no rent, the refile (and its undo), and undo; a cross-company test for every call that takes an id (`list_utility_payers`, `set_utility_payer`, `answer_utility_refund`, `mark_utility_refunds_seen`, `refile_utility_refund`), with a positive control that the owner still gets their own row; a viewer is refused each write; Deno tests for the tools, with a wrong-company and an expired-key case.
