# FLOW-1261 · Perf: the Loans list's balances read does not send the currency twice
- **Type:** SMALL (perf) · **Status:** done (#1255) · **Source:** the perf steward's 2026-11-23 [report](../../qa/perf/2026-11-23.md), diff review (response fields), row 1.
- **Files:** `app/src/screens/loan-reads.ts`, `app/src/screens/loan-list.tsx`, their tests.

`readLoanBalances` selects `currency` from `loan_balances`, but the same list already reads `loans.currency`, and the view defines its `currency` as `l.currency`, so the two cannot differ. It is read once, as a fallback to the same value (`balance?.currency ?? loan.currency`). About 374 of the select's 3,073 bytes on Flow QA (22 loans). flow-mcp does not read this select.

- [x] Drop `currency` from the `loan_balances` select in `readLoanBalances` and read the loan's own currency.
- [x] Tests: the Loans list shows the same currency for every loan.

**Acceptance:** the select has no `currency`; every figure unchanged; the tests pass.
