- [x] **Month-drill arrows while months load (#1046 N1): decided, kept screen-reader only (the app’s pattern for disabled chevrons).** Why:
  - The failed state's visible line ("לא הצלחנו לטעון את החודשים.") is not in the band. It sits in the page's `top` slot, above the month's groups. The same line for loading would show for the moment the months take to arrive and then go, so the groups would jump up at 320 and 393. A short caption under the pill would grow the band the same way, and the band's CSS (`61-reports-v3.css`) is out of this PR's scope.
  - A native tooltip is not an option. `IconButton` drops a native `title` on purpose, and a tooltip never shows on a phone anyway.
  - So the chevrons stay dimmed, with "החודשים עוד נטענים" for screen readers (FLOW-1102). The wait usually lasts well under a second. If the owner wants the word visible, the place for it is a reserved line in the band, which belongs in a reports CSS task.
- [x] **`top={attention ?? monthsFailed}` (#1046 N4).** It now reads `top={drill == null ? attention : monthsFailed}`. `attention` is null in a drill and `monthsFailed` is null outside one, so nothing changes.
- [x] **Component shots (#1046 N2).** `components-attentioncards--all-hidden` was re-shot at 320 and 393, light and dark, after its play ends ("אין מה לטפל · הכול נסקר" visible) and every finite animation finishes. `scripts/story-shots.mjs` waits for animations only at render, before the play's clicks, so it caught the enter animation half-way. The story itself is right, so no code changed.
