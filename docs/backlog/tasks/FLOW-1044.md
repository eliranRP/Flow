The project page keeps today's band and its net cash figure (the owner: keep the look). Everything under it is recomposed on the Overview pattern, with the shared parts of FLOW-1043.

- [x] **`/projects` as an Overview.** A band (the period pill with arrows, the month's net cash across projects as the big figure, נכנס and יצא rows), then (the owner, 2026-11-05: no דורש טיפול on the list; each project's page keeps its own, and the lines with no project are one quiet row at the end of the list)  a `SegmentedControl` that docks (`useDockedFilter`): הכול / פעילים / הסתיימו as the board draws it, and the project rows in groups by kind (שיפוץ, השכרה, לקוח, תקורה) with one-line `GroupHead`s (count and total) that stick. A row is today's `ProjectCashRowItem` with a `StatusMark` where the board shows one. The `CompanyCashCard` (next month) leaves this screen (the month drawer and the forecast screen hold it). The compact bar is the band bar, docked when the control reaches it.
- [x] **The project page by kind.** `ProjectCashOverview` reads the kind (plan §5) and composes: renovation shows the budget card with its bar and "עריכה", rental the returns card with "פירוט" to the investment page, client the contract card with "עריכה"; all three show the attention cards (`storageKey="project:<id>"`), the month's lines in groups (נותר לשלם, שולמו, חד-פעמי when the flag is there) under a docking segment, with sticky heads. "דוחות" opens `/reports/pnl?view=project&project=<id>`; "השקעה והלוואות" opens the investment page; "רווח מתחילת הפרויקט" opens the profit page. The "⋯" sheet lists: עריכת פרטים, השקעה והלוואות, רווח מתחילת הפרויקט, סיום הפרויקט (a confirm inside the sheet, then the toast with ביטול, as today's optimistic finish).
- [x] **New project sheet.** The type is picked first (שיפוץ, השכרה, לקוח, תקורה) and the fields follow it: renovation (purchase, budget, ARV), rental (purchase, rent), client (contract), overhead (none). Save stays enabled; a missing required field shows the line under it with `role="alert"`.
- [x] **Project profit as an Overview.** The band is the profit since the start (or the sale profit for a renovation, with the one-line note that renovation is not in monthly profit), the rows under it income, expenses and the share of general expenses, then a docking segment לפי חודש / לפי קטגוריה with sticky heads; a row opens the lines. Replace the `OrderChips` and the hand-rolled month list.
- [x] **Lines with no project.** A new `/projects/unassigned` List screen over `search_transactions` with `project=none`: back link, title, the count and total, 64px rows; "שיוך" opens the project picker sheet with a suggested project (the one the category points to, when there is one), the row folds on assign, a toast with ביטול. The Projects link, the attention card and the profit page's empty state go here.
- [x] Delete what this leaves unused: `project-page-cards.tsx` parts the composition drops, the hand-rolled section heads, the `OrderChips` import on the profit page if nothing else uses it there, CSS blocks.
- **Acceptance:** stories for each kind's page, the list with every filter, docked, the unassigned list (rows, empty, one assigned with its toast), the new-project sheet per type, the profit page both orders, and the `V3-States` states that apply; shots at 320 and 393, dark and light; unit tests for the kind resolution and the row grouping.
