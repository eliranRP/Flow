# FLOW-1188 · A line added to the forecast can be removed from the month's צפי, for that month only or from it on
- **Type:** BUG · **Status:** in-progress (#1158) · **Depends on:** none
- **Source:** the owner, 2026-11-13 (screenshots of תזרים צפוי, נובמבר: two הכנסות שכירות lines): "When I added manually and then remove it, it keeps it in the stream. Also where I added one I can't remove it after that. Also I want to be able to remove from a specific month and not delete for all future terms."
- **Files:** a new migration (`remove_project_forecast_row` and `mcp_remove_project_forecast_row` take a pace), `supabase/tests/database/forecast_removal_pace.test.sql` (new), `packages/shared/src/database.types.ts`, `app/src/project-forecast-writes.ts`, `app/src/screens/forecast-item-page.tsx` (+ test), `app/src/screens/project-next-edit-screen.tsx` (+ test), flow-mcp's `tools_project_forecast.ts`, `tools_specs.ts`, `docs/mcp/TOOLS.md`, `app/src/project-next-edit.ts`, `app/src/screens/project-next-edit-screen.stories.tsx`, `supabase/tests/database/privilege_guards.test.sql`, `docs/decisions/0268-forecast-removal-one-month.md` and its README row, a changelog fragment.

- [x] Cause 1: the תזרים צפוי item page of an added line had no removal. Its only way out was the source row, which opens the project's צפי for next month, so a removal there started next month and the line stayed in this month's stream.
- [x] Cause 2: every removal was from its month on (decision 0239), so the owner could not take a line out of one month only.
- [x] Fix: the item page of an added line gets הסרה מהצפי, with a sheet: רק ב<month> (that month only) or מ<month> והלאה (the line stops; a line that starts that month is deleted). The project's צפי edit page offers the same two choices for every row.
- [x] Server: `remove_project_forecast_row` takes `p_pace` (`once` or `month`, default `month`); `once` writes a removal for that month only and never deletes a line. MCP `remove_project_forecast_row` takes `pace` too.

**Acceptance:** in November, removing an added monthly line "רק בנובמבר" takes it out of November's forecast and leaves it in December's; "מנובמבר והלאה" takes it out of both.
