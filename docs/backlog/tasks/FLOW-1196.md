# FLOW-1196 · Perf: duplicated fields in reads that flow-mcp names
- **Type:** MEDIUM (perf, MCP contract) · **Status:** ready · **Source:** the perf steward's daily diff review, 2026-11-14 ([report](../../qa/perf/2026-11-14.md), finding 11).
- **Files:** migrations for the reads below, `packages/shared` zod schemas, the flow-mcp specs (`tools_specs.ts`, `docs/mcp/TOOLS.md`), app readers, pgTAP.

Fields that repeat other fields. flow-mcp's specs name them, so dropping one changes the MCP contract:

- `company_next_month_inputs`: `edits[]` is repeated inside `rest_edits` when `p_rest` is true (`20261113140335_next_month_lean.sql:252-295`). flow-mcp always gets both. `rest_edits` is 59 KB by that migration's header; the repeated share is unmeasured.
- `get_project`: `categories[]` repeats the ILS rows of `categories_by_currency`, and the `*_agorot` totals repeat the ILS row of `by_currency`.
- `missing_bills`: `supplier_id` and `supplier_name` repeat `party_id` and `party_name`.
- `project_category_months`: `group_name`, `this_month_minor`, `months_seen` and `typical_day` are read by flow-mcp only. The app could ask for a lean form.

**Acceptance:** each change names the MCP tool it affects and updates that tool's spec in the same PR. The PR shows the bytes before and after.
