# FLOW-444 · A project's month profit page names its project
- **Type:** BUG · **Status:** done · **Depends on:** — · **Related:** [FLOW-440](FLOW-440.md), [FLOW-443](FLOW-443.md) (the same pages) · **Source:** owner report 2026-10-11, with a phone shot of a project's month profit page (הפסד <month>). The shot holds real data, so it is not in the repo.
- **What happens:** Opening a month from the project's "לפי חודש" list shows "רווח <month>" or "הפסד <month>", its figure, הכנסות, הוצאות and the transactions. The project's name shows nowhere: Back is a bare arrow, and nothing in the title or the rows says which project this is. Decision [0156](../../decisions/0156-labelled-back-and-compact-bar.md) gives a stacked page with a parent a labelled Back ("‹ שיפוץ הרצל 12"), and the cash month page already labels its Back.
- [x] The month profit page names its project: opened from the project, Back reads "‹ <project>" (cut at about 16 characters); opened from "לפי חודש", Back reads "‹ לפי חודש" and the project's name is the line above the title (0156 note, 2026-10-14). The compact bar keeps Back and the title.
- [x] Check the other project month pages (cash month, "לא נספר ברווח", the by-month list) for the same gap, and give each the project's name the same way.
- [x] Nothing else on the page changes.
- **Done (#597):** the name was there all along, but a labelled Back shows only when Back lands on its fallback (the project), and a month opened from "לפי חודש" goes back to that list, so Back was a bare arrow and the name vanished. Per 0156, Back names where it lands: a month opened from the list now reads "‹ לפי חודש" with the project's name on the line above the title (new `backText` on `ScreenHeader`, new `useBackTarget` in `ui/back.tsx`); opened from the project, Back still reads "‹ <project>". The cash month opened from its year page reads "‹ <year>" with the project's name kept the same way. The "לא נספר ברווח" and נכנס/יצא line pages name their month, which is where Back goes, so they are unchanged. The compact bar keeps its arrow and the page title, per 0156.
- **Acceptance:** stories at 320 and 393 with invented names: the month page with "‹ <name>", including a long name cut with an ellipsis (Screens/Routes, Project one month, long project name), and the from-list header with "‹ לפי חודש" and the name kept (Components/ScreenHeader, BackToListKeepsKicker). A unit test (`ui/back-target.test.tsx`) that Back names the list when the month came from it, names the project when it came from the project, and that the page keeps the project's name.
- **Redesign (2026-10-11):** the approved project month page ([FLOW-140](FLOW-140.md)) has Back "רווח <project>". Whichever ships first gives the page its project's name; the other keeps it.
