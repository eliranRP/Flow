# FLOW-1264 · Loans: a payment not yet split to its loan is not called late
- **Type:** BUG · **Status:** in-progress (#1256) · **Depends on:** FLOW-1258
- **Source:** code review of #1252 (r2), the owner's go 2026-11-23. `loan_balances.last_paid_on` reads only lines split to the loan (`private.loan_parts`), so a bank line that paid the loan but is not split yet makes the loan read late.
- **Files:** `supabase/migrations/20261120214055_flow_1264_loan_unsplit_payments.sql` (view `public.loan_unsplit_payments`), `supabase/migrations.lock`, `supabase/tests/database/flow_1264_loan_unsplit_payments.test.sql`, `packages/shared/src/database.types.ts`, `app/src/screens/loan-reads.ts`, `app/src/screens/loan-list.tsx`, `app/src/screens/loans-live.test.tsx`, `app/src/screens/loan-setup-settings.test.tsx` (the mock answers the new view).

- [x] A security-invoker view `loan_unsplit_payments` (company_id, loan_id, last_on): per open loan with a monthly payment, the latest posted, not removed expense line of the last 75 days (Israel time) in the loan's currency whose amount is within 2% of the payment, that no loan split covers, and whose supplier an earlier line split to this loan came from (code review r1: the supplier ties the line to the loan, so an unrelated expense of about the same amount does not count). Select for authenticated and service_role only.
- [x] The Loans list reads it beside the balances and counts that line as the loan's payment for the late check (the later of it and `last_paid_on`); the line itself still waits in the review queue.
- [x] pgTAP: a matching unsplit line counts; a split one, a removed one, an income, another currency, an amount 5% off and a line older than 75 days, and an expense for exactly the payment from another supplier do not; RLS by company.
