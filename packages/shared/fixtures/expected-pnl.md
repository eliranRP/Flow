# Expected Flow P&L: demo client "Flow Test" (SUMIT 2389917160)

Generated by `pnl.py` from `dataset.py` + `state.json`. All 75 SUMIT documents were read back through `/crm/data/listentities/` (`verify.py`, 0 mismatches). Amounts are **ILS before VAT** and rounded to whole shekels for display; the JSON has exact values. Snapshot as of 2026-09-26.

## Rules Flow must apply to match these numbers
1. **Project** = `BudgetManagement_BudgetItem` (with a fallback to the `פרויקט: <name>` prefix in the description). Receipts are also tagged, and their `Accounting_OriginalDocument` points at the invoice.
2. **Invoiced basis income** = tax invoices + invoice-receipts − credit notes, using `Accounting_DisplayCompanyValueWithoutVAT` (credit notes are already negative).
3. **Cash basis income** = receipts + invoice-receipts. A receipt carries no VAT (`…WithoutVAT` equals the gross amount), so Flow nets it with the linked invoice's VAT rate: net = gross / 1.18. A cheque counts on its receipt date, not its due date. Credit notes don't move cash.
4. **Expenses** (`חשבונית ותשלום לספק/ית`, folder 2375135546, DefinitionEnum 13) are all paid at entry, so cash basis = invoiced basis. **SUMIT stores `addexpense` expenses with no VAT: VAT line 0, no `Accounting_VATRate`, `…WithoutVAT` = gross.** This was verified on all 45 expenses, including suppliers with valid company numbers. So two expected sets are given:
   - **Rule A (the correct before-VAT P&L, main tables):** net = gross / 1.18 for VAT-registered suppliers and net = gross for VAT-exempt ones (insurance: ביטוח המגן). In tech-plan terms, every supplier here has a known VAT rate (`vat_status='derived'`, e.g. via supplier memory or a per-supplier VAT setting).
   - **Rule B (what tech-plan §4 currently specifies: "show gross with `vat_status='unknown'`, don't guess 18%"):** expenses at gross. Flow should then show the "מע״מ לא ידוע" hint, because unknown-VAT expenses are 100% of expenses here. See the Rule B section.
   - Since SUMIT expenses are the main source for contractors, Rule B overstates every expense by 18% for the typical user. **This needs an owner decision (tech-plan Q7).**
5. **Shared cost** (`עלות משותפת:` = site workers, 16,000/month) is untagged. Flow allocates it by worker-days per project per month (`SHARED_ALLOC` in dataset.py). The tables show it both before allocation (as a company line) and after.
6. **Overhead** (`תקורה:`: accountant, insurance, leasing, fuel, phone) is company-level only and never allocated to projects.
7. Income documents are all dated 2026-09 because of SUMIT limitations. Expenses run April to September 2026.
